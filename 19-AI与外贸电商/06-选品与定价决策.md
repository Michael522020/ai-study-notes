# 06 · 选品与定价决策

> **这一章的任务：把「选什么、卖多少」拆成算式，并明确——趋势判断不能交给模型，但把趋势变成可比较的数字可以。**

---

## 1. 选品：AI 该做什么，不该做什么

### 1.1 四种选品逻辑

| 逻辑 | 做法 | AI 适配度 |
|---|---|---|
| **跟爆款** | 跟平台上已经跑出来的品 | **高**（数据抓取 + 聚合） |
| **跟趋势** | 从搜索趋势、社交内容里发现上升品类 | **部分**（数据聚合可，趋势判断不可） |
| **跟供应链优势** | 围绕现有产能与供应商能力找品 | **部分**（结构化匹配可，选品判断不可） |
| **跟需求缺口** | 找到「有需求但供给差」的细分 | **高**（这本质是数据分析） |

**四条里 AI 都擅长「把散落的信号变成可比较的表」。**
**但「这些数字意味着该做这个品」——这是商业判断，模型做不了。**

### 1.2 选品要看的一组指标

```
需求侧:
  搜索量趋势（近 12 个月斜率，不是绝对值）
  关键词的数量分散度（长尾多 = 竞争分散）
  评论数增速（比搜索量更真实，因为它代表成交）
供给侧:
  上架总数与月新增
  Top 10 集中度（越高越垄断）
  Top 10 头部平均评论数（门槛）
  上架后的存活率（大量上架即下架 = 不赚钱）
单位经济:
  到岸成本 / 售价（毛利率）
  退货率（决定有效毛利）
  广告成本占比
```

### 1.3 一个必须自己算的数：有效毛利

```
标价毛利 = (售价 - 到岸成本) / 售价

有效毛利 = (售价 - 到岸成本 - 履约成本 - 退货损失 - 平台佣金 - 广告费 - 汇兑与支付费) / 售价

其中:
  到岸成本 = 出厂价 + 头程 + 关税 + 清关费
  履约成本 = 尾程 + 仓储 + 操作费
  退货损失 = 退货率 × (单次退货的平均损失：退款 + 退货运费 + 商品损耗 + 二次销售折损)
```

**「退货率」在有效毛利里被严重低估。**
一个标价毛利 45% 的品，退货率 25% 且单次退货损失 40% 时，有效毛利会掉到 20% 以下——**这时它就不该做了**。

> **很多「爆款」算完有效毛利是不赚钱的。** 退货率高、尺寸件、易碎、需要复杂说明的品，都是重灾区。
> **选题的第一步不是看它卖得好不好，是算它的有效毛利。**

### 1.4 AI 的真实用法：把「好不好卖」变成「几个可比数字」

```
做：
  - 抓取并归一化多平台的销量/评论数/上架数（注意抓取合规与平台政策）
  - 计算趋势斜率、集中度、存活率、单位经济
  - 输出「候选品对比表」，每一列带数据来源与抓取时间
不做：
  - 判断「这个品会不会爆」
  - 判断「值不值得压货」
```

**「会不会爆」这个问题本身不可回答。** 任何声称能回答的方案都在骗人。
**能回答的是：「这个品的单位经济在这个价格带里处于什么位置」。**

## 2. 定价：把定价变成一个带约束的求解

### 2.1 定价不是"成本加利润率"

一个更完整的定价模型：

```
售价 = f(成本结构, 市场价格带, 需求弹性, 竞争位置, 渠道费用)
```

展开成可计算的约束优化：

```
变量:
  P = 售价
  Q = 预期销量（随 P 变化，见下方）

约束:
  ① 底价: P ≥ 到岸成本 + 最低履约成本 + 最低渠道费    （否则每单亏钱）
  ② 毛利: 有效毛利(P) ≥ 目标毛利率
  ③ 竞争: P ∈ [市场最低价 × (1+δ₁), 市场最低价 × (1+δ₂)]  （价格带锚定）
  ④ 份额: 若按需求曲线 Q(P)，P 变化带来的销量变化要满足战略目标
  ⑤ 政策: P 不低于某些市场的最低定价或宣传价合规要求
```

**AI 的位置：**
- 收集约束 ③ 的市场价与价格带分布 → **可自动化**
- 提供需求曲线 Q(P) 的历史数据 → **可自动化，但要用你自己的销量数据，不是公开数据**
- **解这个优化问题 → 用程序（线性/分段线性规划），不用模型**
- 对结果做情景分析（价格 -5% / -10% / +5% 的利润影响）→ **程序算**

### 2.2 需求曲线的正确用法

**公开数据看不到你这条品的需求曲线。** 你能拿到的只有自己的历史：

```
积累方式:
  每次调价（或每次促销）记录 (P, Q, 其他同期因素)
  定期拟合一条分段的价格-销量关系
  
注意:
  - 节假日、广告投入、库存状态都是混杂变量
  - 样本要够（至少 5~8 个有价格差异的点才有拟合意义）
  - 拟合出来的是「历史关系」，不是因果；换品类、换季节要重新看
```

**没有自己的数据之前，Q(P) 就用行业经验区间做敏感性分析，不要用一个点估计。**

### 2.3 定价的四个常见错误

| 错误 | 后果 |
|---|---|
| 只按成本加成，不看价格带 | 定价脱离市场，买家直接划走 |
| 用竞品最低价当锚 | 陷入价格战，毛利被压穿 |
| 促销期定价不设下限 | 促销价变成新常态，回头涨不上去 |
| 忽略汇率与支付费 | 到账金额与预期差几个点，一年下来是 sizable 的利润 |

### 2.4 汇率：三个必须做的事

```
① 报价/定价表里所有金额都标注：币种 + 汇率取数时间 + 取数来源
② 汇率波动超过阈值（自定，如 3%）时，自动告警并暂停自动发布新价
③ 报价单要有汇率有效期条款（见 03 章）
```

**第 ② 条常被忽略。** 汇率一夜跳 4% 时，还在按旧价自动发布 Listing，就是在系统性地亏钱。

## 3. 价格带：比定价更重要的决策

**「卖多少钱」这个问题，实际上是「卖给谁、凭什么比他们便宜或贵」。**

### 3.1 价格带的四种定位

| 定位 | 做法 | 需要的能力 |
|---|---|---|
| **最低价** | 贴着市场底部 | 极致成本控制 + 供应链议价力 |
| **性价比带** | 比最低价高一点，用「多一点点价值」说清楚 | **产品差异化 + 强内容** |
| **中位带** | 不打价格战，靠信任与品牌 | 品牌、评价数、售后 |
| **高端** | 溢价，靠设计/服务/认证 | 品牌势能与产品本身 |

**AI 对这四种的帮助程度完全不同：**
- 最低价带：**AI 帮助最小**（成本是硬约束）。
- 性价比带与中位带：**AI 帮助最大**（内容与说服力的差距在这里拉开）。
- 高端带：AI 帮助在**内容与视觉**，但溢价要靠产品本身。

### 3.2 「性价比带」的内容要求

**要在一个价格带里胜出，必须能回答「为什么比那个便宜的东西多值这 30%」。**
这个答案必须是**具体且可验证的**：

```
差的答案（无法验证）：
  "品质更好" / "更耐用" / "采用优质材料" / "专业团队打造"

好的答案（可验证）：
  "内壁为 304 不锈钢，检测报告编号 XXXX（可索取）"
  "杯壁厚度 0.6mm，同价位常见 0.3mm（见对比图）"
  "盖体为食品级 PP，不含 BPA（报告 YYYY）"
  "保修 3 年，同价位常见 1 年"
```

**AI 帮的是「把已有的差异点用买家能懂的话写出来」，不是「编出差异点」。**
差异点必须来自产品与检测数据——**这又回到了 [`04`](./04-商品内容与多语种商品页.md) 的事实回指规则**。

## 4. 竞品分析：让 AI 做汇总，不要做结论

### 4.1 竞品表该长什么样

```
SKU | 品牌 | 售价 | 促销价 | 评分 | 评论数 | 上架月数 | 月增评论 | 主图风格 | 五点结构 | 差评高频词
```

**「差评高频词」是这张表里最值钱的一列。**
它同时告诉你两件事：**竞品的软肋**（你可以打）和**买家最在意什么**（你必须做到）。

> **读 50 个竞品的差评，比读 500 篇行业分析报告有用。**
> 而「把 50 个竞品的差评聚类并排序」正是 LLM 擅长的活——**这是 AI 在选品环节最实在的一个用法。**

### 4.2 让 AI 做差评聚类的正确做法

```
输入：某竞品的全部 1~3 星评论（去重、按时间排序）
要求：
  1. 只提取评论中明确提到的产品问题，按「问题类型」归类
  2. 每类给出：问题描述、出现次数占比、典型原话（逐字引用，标出处）
  3. 不做原因推测，不做改进建议，只做归类与计数
  4. 无法归类的单列「其他」，不要硬塞
```

**「不做原因推测」这条很重要。** 让模型顺便给建议，它会开始编；而**原话引用 + 计数**是事实，可以直接用。

### 4.3 抓取的合规边界

抓取竞品数据前先确认：
- 目标平台的服务条款是否允许抓取公开页面
- 是否触及个人数据（评论中的姓名、照片、地理位置要脱敏）
- 抓取频率与 robots 政策

**这一条不能靠"大家都在做"来正当化。** 抓取工具本身不是原罪，**违反平台条款的抓取是**，而被抓的代价是店铺被关。

## 5. 组合决策：单品之外

### 5.1 三个约束同时存在

```
约束 1: 现金
  备货占用 = Σ(单 SKU 备货金额) + 头程在途 + 平台账期

约束 2: 仓位
  仓储位 = Σ(单 SKU 体积 / 体积利用率)

约束 3: 精力
  单 SKU 的运营工时 = 上架维护 + 客服 + 售后 + 广告管理
```

**一个 100 个 SKU 的店铺，每 SKU 的运营工时乘 100 才是真实成本。**
AI 能大幅压缩「上架维护」和「客服」，但压缩不了「售后」和「广告管理」。

### 5.2 长尾与头部的取舍

| | 头部品 | 长尾品 |
|---|---|---|
| 销量贡献 | 高 | 低但总和可观 |
| 毛利 | 低（竞争激烈） | **高** |
| 运营成本 | 高（广告投入大） | 低 |
| 库存风险 | 高（备货多） | 低 |
| AI 可替代度 | 中 | **高**（内容与客服占比高） |

**一个反直觉的结论：长尾品是 AI 内容与客服自动化收益最高的地方。**
头部品的转化主要靠广告和评价数，AI 帮不上太多；长尾品拼的是内容与响应速度，**这正是 AI 能压的**。

> **所以对已有店铺，「给长尾品做 AI 内容与客服」通常比「给头部品做 AI 内容」ROI 更高。**
> 这条建议和直觉相反，但符合「AI 压缩的是信息劳动而不是流量与信任」这个底层逻辑。

## 6. 本章工程结论

1. **AI 擅长把选品信号变成可比数字，不擅长判断「会不会爆」。**
2. **选题第一步是算有效毛利，不是看它卖得好不好。** 有效毛利 = 标价毛利 − 履约 − 退货损失 − 渠道 − 广告 − 汇兑与支付。
3. **退货损失在有效毛利里被严重低估**，高退货率品往往是「算完不赚钱的爆款」。
4. **定价是带约束的求解，用程序解，不用模型解**；模型负责收集价格带与需求曲线的输入。
5. **需求曲线只能来自自己的历史数据**，没有就做敏感性分析，不要用点估计。
6. **汇率三件事**：报价标注取数时间、波动超阈值告警、报价单有有效期条款。
7. **价格带定位比定价更重要**；性价比带要能回答「为什么比便宜的多值这 30%」，答案必须可验证。
8. **竞品差评高频词是最值钱的一列**——既是对手的软肋，也是买家的关注点。
9. **让 AI 做差评聚类时只做归类与计数，不做原因推测**，且要逐字引用原话。
10. **抓取竞品数据前确认平台条款与个人数据处理边界。**
11. **长尾品是 AI 内容与客服收益最高的地方**，因为 AI 压缩的是信息劳动而不是流量与信任。
