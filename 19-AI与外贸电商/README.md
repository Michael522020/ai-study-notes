# 19 · AI 与外贸电商

> **前面十八条主线讲的是「AI 是什么、怎么搭、怎么不炸」。这一条讲的是「把它塞进跨境生意里，哪一格能省钱、哪一格省不了」。**

外贸和跨境电商是少数几个「**AI 的收益能被业务账直接验证**」的领域：询盘少了三个小时、回复成本降了七成、退货率降了两个点，这些都能在当月的利润表上看到。仓库里其他主线大多是「做出来 → 评测 → 上线」，这一条是「**先算账 → 再决定做不做**」。

所以本目录的写法和其他主线有两点不同：

1. **每章都从业务动作出发，不从技术出发。** 不是「怎么微调一个模型」，而是「询盘来了，谁来分、谁来回、错回一封的代价是多少」。
2. **能算的账都写成公式，不能算的账都标成「要自己测」。** 本章里的成本、时延、命中率都给的是**数量级与算法**，不是引用来的百分比——**引用来的百分比一旦错了，整章的决策就会跟着错**。

本目录与 [`16-多语言与跨境应用`](../16-多语言与跨境应用) 是**互补关系，不重叠**：

| | 16 主线 | 本目录 |
|---|---|---|
| 关注点 | 多语言模型能力、术语一致性、评测方法、数据主权与制裁筛查 | 把 AI 放进一条完整外贸业务链的**运营层面** |
| 典型问题 | 「模型在德语上到底行不行」「术语怎么不翻错」 | 「这个环节该不该上 AI」「上错了损失多少」「六个人的团队怎么排工」 |
| 合规部分 | 数据合规与贸易合规的**框架** | 落到**具体要办的证、要挡的名单、要留的凭证** |

16 主线提供机制，本目录提供**落点**。涉及多语言技术细节时，本目录只给结论并指回 16 主线。

## ⚡ 一张表看懂「外贸链条上 AI 能干什么」

> **口径提醒**：下表是**作者按业务动作拆解的适配度判断**，不是行业统计。
> 「适合」指**收益可验证、出错可回滚**；「部分适合」指**部分子步骤适合**；「不适合」指**出错代价高且难以自动发现**。

| 业务环节 | 原始动作 | AI 适配度 | 为什么 | 出错代价 |
|---|---|---|---|---|
| 获客 | 搜名录、翻海关数据、发开发信 | **部分适合** | 找线索是检索问题，可做；**判断对方值不值得跟**是商业判断 | 低（漏一个客户不致命） |
| 线索筛选 | 人工看官网、读询盘 | **适合** | 读文档 + 套模板判断，**输出可复核** | 低（错筛可回看） |
| 询盘首响 | 人工查规格、报价、写信 | **适合** | 知识检索 + 生成 + 人工一键确认 | 中（回错要靠人工补救） |
| 报价与打样 | 算成本、议价、排产 | **部分适合** | 成本计算是确定性任务（可做成程序）；**议价是人的判断** | 高（报错价直接亏钱） |
| 商品内容 | 写标题、五点、详情页 | **适合** | 结构化输入 → 结构化输出，**可批量可复核** | 中（影响转化，不影响现金流） |
| 多语种本地化 | 翻译 + 改写 | **部分适合** | 直译可自动，**跨文化改写要人审**（见 16 主线） | 中高（文化事故伤品牌） |
| 售前客服 | 回答重复问题 | **适合** | 高频、低风险、有知识库 | 低 |
| 售后与退换货 | 判责 + 退款 | **部分适合** | 判责要规则化，**退款金额必须有闸** | 高（无闸会亏钱） |
| 差评处理 | 公关回复 | **部分适合** | 生成草稿可以，**对外发声必须人工签字** | 高（公开声誉） |
| 选品 | 盯趋势、算市场 | **部分适合** | 数据聚合可自动，**趋势判断不可自动** | 中（压了货） |
| 定价 | 算成本、定价格带 | **适合** | 公式化，**但汇率与税费必须由外部数据源喂** | 高 |
| 物流履约 | 订舱、报关、发货、跟踪 | **部分适合** | 轨迹聚合可自动，**异常决策需人** | 高（断链=断货） |
| 合规筛查 | 查名单、查认证 | **适合（且必须）** | 规则明确，**能做成硬闸** | 极高（法律） |
| 对外文件 | 合同、发票、报关单 | **不适合（交给程序）** | **要的是确定性，不是智能** | 极高 |

**从这张表能读出一条主线：**

> **AI 适合接管「读、判断、写」，不适合接管「算钱、担责」。**
> 凡是出错的代价会直接变成现金流出或法律责任的环节，要么做成确定性程序（规则引擎 + 审批），要么留人工闸。

## ⚠️ 关于本章数据的性质

- 本目录中的**所有业务数字均为「数量级示例」或「可自己测的公式」**，用于说明量级关系与算法，**不构成对任何平台、任何品类的市场统计引用**。真实数据请以平台后台、第三方数据服务与自己的经营数据为准。
- 涉及**关税、增值税、出口管制、制裁名单、产品认证**的内容为**工程侧常识性说明，不构成法律或税务意见**。各市场的规则变动频繁且按 HS 编码与原产地细分，**真实决策前必须由报关行、税务顾问或目标市场律师复核**。
- 本目录**不含任何真实客户、真实询盘、真实报价、真实订单或真实公司数据**；出现的品类、国家、公司规模、价格带均为**示意**，不指向任何具体企业。
- 成本示例统一以「单次调用 × 单价」的形式给出，**单价请回各服务商当期定价页核对**（模型价格与平台费率都变动很快）。
