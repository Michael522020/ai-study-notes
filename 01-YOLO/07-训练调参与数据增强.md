# 训练调参与数据增强

> **核心问题**：为什么大家都在用 YOLO，但效果差很多？答案往往不在模型，而在**训练配方**。

### 1.2 学习率策略

**为什么需要 warmup？**
训练初期，模型权重接近随机初始化，梯度的尺度和方向都不稳定。大学习率容易让模型发散。

Ultralytics 的 warmup 实现：
```
warmup_iterations = max(round(warmup_epochs * nb), 100)
if it <= warmup_iterations:
    xi = [0, warmup_iterations]
    # accumulate: 从 1 累到 nbs（nominal batch size）
    accumulate = max(round(nbs / batch_size), 1)
    for j, x in enumerate(warmup_bias_lr):
        # 线性插值 lr 从 warmup_bias_lr[j] 到 lr0
        interpolate = ...
```

**Cosine 退火**：
$$
\text{lr} = \text{lr}_0 \left(\frac{1 - \cos(\frac{t}{T}\pi)}{2}\right)\left(\text{lr}_0 - \text{lr}_0 l\right) + \text{lr}_0 l
$$

**关键**：最后一个 epoch 把 `lr` 置零（或 `lrf` 比例），让模型「收敛到一点」，这通常能再提升 0.2~0.5 mAP。

### 1.3 权重衰减的正确用法

| 优化器 | 建议 weight_decay |
|---|---|
| SGD | 0.0005 |
| AdamW | 0.05（Ultralytics v8 会自动转换） |
| Adam | 0（Adam 的 L2 正则效果差） |

**不要衰减的层**（YOLOv5 的做法）：
- 所有 `Conv` 的 weight
- 所有 `BatchNorm` 的 weight 和 bias
- **bias**（包括检测头的 cls/obj bias）

```python
# YOLOv5 build_optimizer
g_bn, g_w, g_b = [], [], []  # BN 权重 / 普通权重 / bias
for v in model.modules():
    if hasattr(v, 'bias') and isinstance(v.bias, nn.Parameter):
        g_b.append(v.bias)
    if isinstance(v, nn.BatchNorm2d):
        g_bn.append(v.weight)
    elif hasattr(v, 'weight') and isinstance(v.weight, nn.Parameter):
        g_w.append(v.weight)
optimizer = torch.optim.SGD(g_bn, lr=lr0, momentum=momentum, nesterov=True)
optimizer.add_param_group({'params': g_w, 'weight_decay': weight_decay})
optimizer.add_param_group({'params': g_b})
```

### 1.4 Batch size 与梯度累积

**核心概念**：Ultralytics 的 `nbs`（nominal batch size，默认 64）是**权重衰减的参考基准**。

$$
\text{accumulate} = \max\left(\text{round}\left(\frac{nbs}{batch\_size}\right), 1\right)
$$

- 实际 batch=8，nbs=64 → accumulate = 8
- 梯度累积 8 步后更新一次 → 有效 batch = 64
- **但权重衰减要按比例缩放**：$\text{wd\_scaled} = w_d \times \frac{batch\_size \times \text{accumulate}}{nbs}$

**为什么重要**：如果你用 batch=4 训练但不做这个缩放，等效学习率会偏大，容易在后期震荡。

### 1.5 EMA（指数滑动平均）

$$
w_t = \alpha w_{t-1} + (1-\alpha) w_t^{\text{raw}}, \quad \alpha = 0.9999
$$

- 评估时使用 EMA 权重（`model.ema`)
- **作用**：平滑参数更新轨迹，抵消 SGD 噪声
- **收益**：通常 +0.3~0.8 mAP，几乎零成本
- **注意**：`ultralytics` 中 EMA 的 `updates` 计数用于动态调整 decay（前期用小 decay）

```python
class ModelEMA:
    def __init__(self, model, decay=0.9999, tau=2000, updates=0):
        self.ema = deepcopy(model).eval()
        self.updates = updates
        self.decay = lambda x: decay * (1 - math.exp(-x / tau))
    def update(self, model):
        self.updates += 1
        d = self.decay(self.updates)
        msd = model.state_dict()
        for k, v in self.ema.state_dict().items():
            if v.dtype.is_floating_point:
                v *= d
                v += (1 - d) * msd[k].detach()
```

### 1.6 闭集自训练（Self-Training / Pseudo-Labeling）

**原理**：用模型自己的预测作为伪标签，训练新数据。这在半监督/低标注场景极其有效。

**YOLOv5 的实现**（`val.py` 里的 `autolabel`）：

```bash
# 1. 用当前模型预测，生成伪标签
python val.py --weights yolov5s.pt --data custom.yaml --task detect \
              --save-txt --save-conf --save-json

# 2. 把伪标签作为训练集（需要把 images/labels 结构组织好）
#    labels/xxx.txt 内容: class x_center y_center w h  （归一化）

# 3. 重新训练
python train.py --weights yolov5s.pt --data custom.yaml
```

**伪标签的关键参数**：`--save-conf` 要设得**足够高**（如 0.25~0.5），否则低质量伪标签会污染训练。

**伪标签的三条经验法则**：
1. **置信度阈值高**（0.25+），宁可漏标不可错标
2. **保留 GT 不覆盖**：已标注的数据保留人工标签，只对未标注数据生成伪标签
3. **迭代 2~3 轮**：超过 3 轮基本收敛，继续迭代容易过拟合到自己的错误

## 2. 数据增强全景

### 2.1 几何增强

| 增强 | 参数 | 作用 | 风险 |
|---|---|---|---|
| **RandomFlip (h)** | `fliplr=0.5` | 左右翻转 | 文字类数据集要关 |
| **RandomFlip (v)** | `flipud=0.0` | 上下翻转 | 几乎所有自然图像要关 |
| **RandomRotate** | `degrees=0.0` | 旋转 | 航拍要开（10~180） |
| **RandomTranslate** | `translate=0.1` | 平移 | 通用 |
| **RandomScale** | `scale=0.5` | 缩放 | 通用；小目标数据集可加大 |
| **RandomShear** | `shear=0.0` | 剪切 | 少用 |
| **RandomPerspective** | `perspective=0.0` | 透视变换 | 文档/场景文本有用 |

### 2.2 Mosaic（四图拼接）

**原理**：把 4 张图拼成 2×2 的新图，每张图的标签相应变换。

```
┌─────────┬─────────┐
│  img1   │  img2   │
│  ┌───┐  │         │
│  │box│  │         │
├───┼───┴─────────┤
│  img3   │  img4   │
│         │  ┌───┐  │
│         │  │box│  │
└─────────┴───┴───┴──┘
```

**为什么有效？**
1. **一次 batch 内引入 4 倍的目标数量** → 小目标的正样本密度提升
2. **强制模型学习部分目标**（每张图只占 1/4）→ 逼迫模型关注局部特征
3. **扩大数据分布** → 相当于 4× 数据量

**关键实现细节（Ultralytics）**：
- 新图尺寸 2× 原图（如 1280×1280）
- 4 张图**随机**放置在 4 个格子中（不是严格 2×2 排列）
- 缩放系数随机选 0.5~1.5
- 拼接边界处会做**颜色空间混合**（用 random.uniform 随机偏移 rgb 通道值）

**Mosaic 的副作用**：
- 破坏了图像的全局上下文（航拍/文档场景可能有害）
- 拼接边界产生不自然的图像
- **必须关闭**：最后 10~15 epoch（`close_mosaic=10`）

### 2.3 MixUp

**原理**：两张图按比例线性混合，标签按相同比例混合。

$$
x' = \lambda x_1 + (1-\lambda) x_2, \quad y' = [\lambda y_1, (1-\lambda) y_2]
$$

- $\lambda \sim \text{Beta}(\alpha, \alpha)$，Ultralytics 默认 $\alpha = 0.2$
- **对检测**：YOLOv5 的实现是**把两张图 resize 到同一尺寸后 concat（横向拼接）**，而不是像素级混合——像素级混合会破坏目标的可辨识度

```python
# YOLOv5 的 mixup 实现（labels 也相应处理）
def mixup(imgs, labels, mosaic):
    # 随机选择两图拼接（横向）
    j = random.choices(range(n), k=2)
    ...
    # labels 的 x 坐标按宽度比例调整
```

**收益**：约 +0.5~1 mAP（数据集小的时候收益更大）

**副作用**：降低定位精度（因为标签边界变模糊），在定位精度敏感的任务上可能掉点。

### 2.4 Copy-Paste（实例级复制粘贴）

**原理**：把一张图中的实例抠出来，粘贴到另一张图的随机位置。

**与 Cutout 的区别**：
- Cutout：贴**噪声块**（遮挡）
- Copy-Paste：贴**真实实例**（增强）

**两种模式**（YOLOX 论文）：
- `flip`：水平翻转实例后粘贴
- `class`：把同类实例整批粘贴

**收益**：对小目标、遮挡场景提升明显。

**注意**：需要用分割 mask 来抠实例（YOLOX 用 polygon mask）。如果只有检测框标签，可以退化为「按框裁剪 + 不做 mask」。

### 2.5 颜色空间增强

| 增强 | 参数 | 作用 |
|---|---|---|
| **HSV-Hue** | `hsv_h=0.015` | 色调（对颜色敏感的类别要小） |
| **HSV-Saturation** | `hsv_s=0.7` | 饱和度 |
| **HSV-Value** | `hsv_v=0.4` | 明度（模拟光照） |

**注意事项**：
- **火灾/烟雾检测**：`hsv_h` 要调小，否则火焰颜色会变
- **交通标志识别**：`hsv_s` 和 `hsv_v` 都要小，否则红色会变成其他颜色
- **夜间数据集**：适当增大 `hsv_v`

### 2.6 高级增强（YOLOX 引入，Ultralytics v8 有 `imgsz` 级别的 Albumentations）

| 增强 | 作用 |
|---|---|
| **Mosaic + RandomPerspective** | 组合使用 |
| **HSV + RandomFlip** | 基础 |
| **Blur / MedianBlur** | 模糊鲁棒性 |
| **CLAHE** | 对比度受限自适应直方图均衡，夜间/逆光场景有用 |
| **RandomGamma** | gamma 变换 |

### 2.7 闭集自训练的数据增强（半监督）

**Unbiased Teacher / Soft Teacher** 的核心思想：
- 教师模型在**强增强**下产生伪标签
- 学生模型在**弱增强**下学习

**为什么有效**：强增强破坏了低置信度目标，教师只输出高置信度伪标签 → 伪标签质量高。

**YOLOv5 的 `hyp` 中没有内置**，需自行实现。

## 3. 增强的「负空间效应」

**关键现象**：过度增强会**降低**精度。

| 数据集规模 | 推荐强度 |
|---|---|
| < 500 张 | 弱增强 + 闭集自训练 + 更长训练 |
| 500 ~ 5000 张 | 中等增强（mosaic=1.0, mixup=0.0~0.1） |
| > 5000 张 | 中等偏强（mosaic=1.0, mixup=0.1~0.2, copy_paste=0.1） |
| > 50000 张 | 强增强（+ scale=0.7, mosaic 持续到最后） |

**实验方法**：固定其他超参，逐一开关增强，测 mAP。**不要盲调**。

## 4. 训练配方速查表

### 4.1 场景配方

| 场景 | 推荐配置 |
|---|---|
| **小目标密集（航拍/交通）** | `scale=0.9, mosaic=1.0, close_mosaic=15, imgsz=1280, copy_paste=0.1` |
| **密集小目标（细胞/缺陷）** | `mosaic=1.0, scale=0.5, degrees=180, translate=0.2` |
| **固定场景（室内/货架）** | `degrees=0, translate=0.1, scale=0.3, mosaic=0.5, hsv_s=0.3` |
| **自动驾驶（KITTI/nuScenes）** | `degrees=0, translate=0.1, scale=0.5, mosaic=1.0, close_mosaic=10, rect=False` |
| **文本/文档** | `degrees=0, scale=0.3, mosaic=0.3, hsv_s=0.15, hsv_v=0.2, fliplr=0.0` |
| **极小数据集（<100 张）** | `mosaic=1.0, mixup=0.1, epochs=300, lr0=0.001, warmup=5, 闭集自训练` |
| **大规模（>10 万张）** | `epochs=100, lr0=0.01, mosaic 保持, scale=0.7` |

### 4.2 训练命令模板

```bash
# 基线训练
yolo detect train model=yolo11s.pt data=coco.yaml epochs=100 imgsz=640 batch=16 \
     device=0 workers=8 project=runs/exp name=baseline

# 消融：只改一个变量
yolo detect train model=yolo11s.pt data=coco.yaml epochs=100 imgsz=640 batch=16 \
     hsv_h=0.0 hsv_s=0.0 hsv_v=0.0 name=ablate_no_hsv

# 小目标专项

     scale=0.9 close_mosaic=15 copy_paste=0.1 name=ablate_small

# 续训（从中断恢复）
yolo detect train model=runs/exp/weights/last.pt resume=True

# 从头训练（不用预训练权重）
yolo detect train model=yolo11s.yaml data=coco.yaml pretrained=False
```

## 5. 调试诊断清单

训练不收敛 / mAP 低时，按顺序排查：

| 顺序 | 检查项 | 方法 |
|---|---|---|
| 1 | **标签格式** | 抽查 20 张图，`labels/*.txt` 与图对应；类别 id 连续；坐标是归一化的 0~1 |
| 2 | **类别 id 是否从 0 开始** | `yaml` 里的 `names` 索引要和 label 一致 |
| 3 | **图像和标签是否一一对应** | 数量一致，无缺失 |
| 4 | **预训练权重** | 用 `.pt` 而不是 `.yaml` |
| 5 | **学习率** | batch 小的时候调低 lr0 |
| 6 | **增强是否过强** | 关掉所有增强跑一次，看 mAP 是否上升 |
| 7 | **类别极度不平衡** | 看 `train_batch*_labels.jpg`，长尾类别几乎没有样本 |
| 8 | **正负样本分配** | 检查 TAL 的 topk=10 对你的目标密度是否够 |
| 9 | **过拟合迹象** | train loss 持续降但 val mAP 不涨 → 数据太少或增强不够 |

**看这张图**：`runs/exp/results.png`（训练曲线）、`runs/exp/train_batch0_labels.jpg`（**模型预测的标签 vs GT 叠加**，能一眼看出标签格式错没错）。

## 6. 工程结论

1. **闭集自训练是投入产出比最高的手段**。标注 1000 张 + 自训练 3 轮 ≈ 标注 5000 张的效果（在多数场景下）。
2. **`close_mosaic` 别忘了开**。这是 YOLO 系列最容易被忽略的一个超参，通常 +0.3~1 mAP。
3. **对小数据集，先调增强，再调模型**。用 yolo11s + 好增强 > yolo11x + 乱增强。
4. **`scale` 参数对小目标数据集的收益最大**，但过大（>0.7）会导致训练不稳定。
5. **权重衰减要跟着 batch size 缩放**，Ultralytics 已经处理了；如果你自己写训练循环，务必注意。
6. **保存 `train_batch*_labels.jpg` 并每次训练都看**，这是 90% 标签问题的快速定位手段。
