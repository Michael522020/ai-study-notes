# agent-learning

记录我在 agent / LLM 应用方向的学习笔记、读源码心得与可复用的脚手架。

## 目录约定

- `notes/` — 按日期或主题组织的学习笔记（Markdown）
- `examples/` — 配套的小示例代码
- `references/` — 论文 / 文档 / 链接

每个文件以日期开头，例如 `notes/2026-10-21-agent-construction.md`。

## 风格

- 第一遍先抄定义，第二遍谈自己的理解和工程取舍
- 末尾留一句"一句话总结"，把最核心的心得收紧
- 代码片段尽量能独立跑通；不能跑的写明依赖
- 不上传任何环境配置、密钥、模型权重
