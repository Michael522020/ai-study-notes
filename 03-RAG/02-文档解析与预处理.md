# 文档解析与预处理

> **核心问题**：RAG 的效果上限由解析决定。PDF 解析不好，后面全是白干。

---

## 1. 为什么解析是第一优先级

**典型失败案例**：

```
原始 PDF：一段排版复杂的合同条款
   ↓ 解析器只提取纯文本
   ↓ 得到："甲方乙方双方应当根据本合同约定..."
   ↓ 切分
   ↓ chunk 1: "...根据本合同"
   ↓ chunk 2: "约定乙方应..."
   ↓ 嵌入
   ↓ 检索时，"违约责任" 相关的 chunk 完全没被召回
```

**根本问题**：**文本流 ≠ 语义流**。PDF 是「排版格式」，不是「结构化文档」。

**关键统计**（业界经验）：
> 一个 RAG 系统效果不好，**60% 的原因在解析/切分，30% 在检索，10% 在生成**。

---

## 2. 各格式的解析难点

| 格式 | 难点 | 推荐工具 |
|---|---|---|
| **纯文本 / Markdown** | 无 | 直接读 |
| **HTML** | 导航/广告/页脚噪声 | BeautifulSoup + 正文提取 |
| **DOCX** | 表格、图片、批注 | python-docx + 表格转 Markdown |
| **PDF（数字版）** | 双栏、页眉页脚、阅读顺序、表格 | PyMuPDF / pdfplumber / MinerU / Docling |
| **PDF（扫描版）** | 图片 | **OCR**（PaddleOCR / MinerU） |
| **PPT** | 形状、备注 | python-pptx |
| **Excel** | 多个 sheet、公式 | openpyxl / pandas |
| **数据库** | — | 直接查，不走 RAG |
| **网页** | 动态加载 | Playwright + trafilatura |

### 3.2 PyMuPDF 快速上手

```python
import fitz  # PyMuPDF

doc = fitz.open("paper.pdf")
pages = []
for page in doc:
    # 基础：直接取文本
    text = page.get_text("text")
    # 按块取（保留阅读顺序）
    blocks = page.get_text("blocks")  # (x0,y0,x1,y1, text, block_no, block_type)
    pages.append(text)
```

**进阶：去掉页眉页脚**
```python
def clean_page(page, header_height=50, footer_height=50):
    h = page.rect.height
    blocks = page.get_text("blocks")
    kept = []
    for b in blocks:
        x0, y0, x1, y1, text, *_ = b
        if y1 < header_height or y0 > h - footer_height:
            continue          # 页眉页脚
        kept.append(text)
    return "\n".join(kept)
```

**进阶：双栏检测**
```python
def detect_columns(page):
    """根据文本块的 x 坐标聚类，判断单栏还是双栏"""
    blocks = [b for b in page.get_text("blocks") if b[6] == 0]  # type 0 = text
    if not blocks:
        return 1
    mid = page.rect.width / 2
    left = sum(b[2] for b in blocks if b[0] < mid) / max(1, sum(1 for b in blocks if b[0] < mid))
    right = sum(b[0] for b in blocks if b[0] >= mid) / max(1, sum(1 for b in blocks if b[0] >= mid))
    # 右侧块左边界明显靠右 → 双栏
    return 2 if (right > page.rect.width * 0.5 and left < page.rect.width * 0.5) else 1
```

### 3.3 pdfplumber 提取表格

```python
import pdfplumber

with pdfplumber.open("report.pdf") as pdf:
    for page in pdf.pages:
        tables = page.extract_tables()
        for t in tables:
            # 转 Markdown 表格
            print(markdown_table(t))
```

```python
def markdown_table(rows):
    if not rows:
        return ""
    out = ["| " + " | ".join(str(c or "") for c in rows[0]) + " |"]
    out.append("|" + "|".join(["---"] * len(rows[0])) + "|")
    for r in rows[1:]:
        out.append("| " + " | ".join(str(c or "") for c in r) + " |")
    return "\n".join(out)
```

**表格处理的两种策略**：

| 策略 | 说明 | 适用 |
|---|---|---|
| **整表转 Markdown** | 保留表格结构 | 表格小、结构清晰 |
| **按行转文本** | 每行变成一句陈述 | 表格大、需要按行检索 |
| **表格摘要 + 原文** | LLM 生成表格摘要，附原文 | 表格复杂（财务报表） |

## 4. OCR 方案

### 4.1 何时需要 OCR

| 情况 | 需要 OCR |
|---|---|
| 扫描件 PDF（图片型） | ✅ 必须 |
| 文档内嵌图片（截图、扫描页） | ✅ 需要（局部） |
| 纯数字 PDF（有文本层） | ❌ 不需要（直接抽文本更准） |
| 表格里的图片文字 | ✅ 需要 |

**判断方法**：
```python
import fitz
doc = fitz.open("file.pdf")
text = doc[0].get_text("text")
if len(text.strip()) < 50:      # 文本层几乎没有内容
    print("扫描件，需要 OCR")
```

### 4.2 PaddleOCR / PP-Structure

```python
from paddleocr import PaddleOCR

ocr = PaddleOCR(use_angle_cls=True, lang="ch", show_log=False)

result = ocr.ocr("scan.jpg", cls=True)
for line in result[0]:
    box, (text, score) = line
    print(f"{text}  ({score:.2f})  {box}")
```

**PP-Structure** 进一步做版面分析：
```
PP-Structure:  图像 → 版面分析 → 文本识别 → 表格识别 → 整体还原
   ├── Layout:   区分 标题/段落/表格/图片
   ├── OCR:      文本识别
   └── Table:    表格结构还原
```

## 5. 文档清洗

### 5.1 常见噪声

| 噪声 | 影响 | 处理 |
|---|---|---|
| 页眉/页脚 | 每页重复，污染切分 | 按位置过滤 |
| 页码 | 同上 | 正则删除 |
| 目录 | 打断语义 | 单独处理或删除 |
| 参考文献 | 干扰检索 | 标记为低优先级 |
| 水印 | 字符混入 | 检测并删除 |
| 连字符断词 | "informa-\ntion" → "information" | 恢复 |
| 换行符 | "abc\ndef" 变成两个词 | 视情况合并 |
| 空白行 | 切分点混乱 | 归一化 |

### 5.2 清洗流程

```python
import re

def clean_text(text: str) -> str:
    # 1. 统一换行和空白
    text = text.replace('\r\n', '\n').replace('\r', '\n')
    text = re.sub(r'[ \t]+', ' ', text)
    text = re.sub(r'\n{3,}', '\n\n', text)

    # 2. 修复断词（行尾连字符）
    text = re.sub(r'(\w)-\n(\w)', r'\1\2', text)

    # 3. 去掉常见的孤立页码
    text = re.sub(r'\n\s*\d{1,4}\s*\n', '\n', text)

    # 4. 去掉零宽字符和 BOM
    text = text.replace('﻿', '').replace('​', '')

    # 5. 去掉常见的项目符号前缀（可选）
    # text = re.sub(r'^\s*[•·▪◦]\s*', '', text, flags=re.M)

    return text.strip()
```

### 5.3 代码块和表格的保护

**关键**：清洗时**不要破坏代码和表格的结构**。

```python
def protect_blocks(text: str):
    """把代码块和表格替换成占位符，清洗完再还原"""
    blocks = []
    def repl(m):
        blocks.append(m.group(0))
        return f"\x00BLOCK{len(blocks)-1}\x00"
    # 代码块
    text = re.sub(r'```.*?```', repl, text, flags=re.S)
    return text, blocks
```

## 8. 表格与图片的特殊处理

### 8.1 表格的三种策略

```python
# 策略 A：整表保留结构
table_md = "| 列1 | 列2 |\n|---|---|\n| 数据 | 数据 |"

# 策略 B：按行展开为陈述句（适合按行检索）
for row in rows[1:]:
    text = "；".join(f"{header[i]}是{row[i]}" for i in range(len(header)))

# 策略 C：摘要 + 原文（适合大表）
```

### 8.2 图片的处理

| 方案 | 说明 | 成本 |
|---|---|---|

### 9.1 基于内容哈希的增量

```python
    return hashlib.sha256(content.encode()).hexdigest()[:16]
```

### 9.2 文档级去重

```python
from collections import defaultdict

# 用 SimHash 或 MinHash 检测近似重复
def simhash(tokens, bits=64):
    v = [0] * bits
    for t in tokens:
        h = int(hashlib.md5(t.encode()).hexdigest(), 16)
        for i in range(bits):
            v[i] += 1 if (h >> i) & 1 else -1
    return sum(1 << i for i in range(bits) if v[i] > 0)
```

**为什么要去重**：
- 同一份文档的多个版本会互相污染检索
- 模板化的文档（如工单）大量重复

## 11. 工程结论

1. **解析决定上限**。RAG 效果不好时，**第一件事是看解析结果**，而不是换嵌入模型。
2. **优先用「结构化输出」的工具**（Docling / MinerU / Unstructured），不要自己撸 PDF 解析。
3. **Markdown 是最好的中间格式**，标题层级天然就是切分边界。
4. **元数据要提前设计**。权限过滤、引用定位都依赖它，事后补很痛。
5. **扫描件必须 OCR**，但要先判断是否真的需要（数字 PDF 用文本抽取更准）。
6. **清洗时保护代码和表格**，别把它们洗成散文。
7. **用可视化工具检查解析质量**，别只看最终的 markdown 文本。
