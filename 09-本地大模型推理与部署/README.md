# 09 · 本地大模型推理与部署

> **从「模型训好了」到「模型在你机器上跑起来」：后端、量化、思考、对齐、工程接入。**

前面几条主线讲的是**模型本身**——怎么训（`06-大模型训练`）、怎么检索（`03-RAG`）、怎么部署视觉权重（`04-边缘部署与端侧AI`）。中间缺了一环：**大模型作为一个软件，是怎么被跑起来的**。

这一条主线补这一环。写法上照旧按「一次真实部署」组织：数字要么标**本机实测**（带日期），要么标**转述公开报告值**，不混用。

本目录的所有实测都在一台**没有独立显卡**的笔记本上完成（i5-13500H + Intel Iris Xe 核显 + 31.7 GB RAM / Windows 11），工具链是 **Ollama 0.40.16 + qwen3:4b（Q4_K_M）**。

## ⚡ 一张表看懂「同一个 qwen3:4b 在不同后端上」

> **口径提醒**：生成速度为**端到端生成速率**（`eval_count / eval_duration`），不含加载时间与 prompt 评估时间；固定 `temperature=0`、`num_predict` 固定、同一条中文提示词。
> 「本机实测」行来自 [`01`](./01-本机部署实战-Ollama在无独显笔记本上的实测.md)；其余为转述公开报告值。

| 后端 | 硬件 | 速度 | 模型驻留 | 数据来源 |
|---|---|---|---|---|
| CPU（AVX2） | i5-13500H | **13.2 tok/s** | 系统内存 | 本机实测（2026-11-12） |
| **核显（Vulkan）** | Iris Xe | **13.7 ~ 14.1 tok/s** | **全部在显存** | 本机实测（2026-11-12） |
| 核显（Vulkan） | Iris Xe | **12.8 ~ 13.1 tok/s** | 全部在显存 | 本机实测（2026-11-14） |
| 独显（CUDA） | NVIDIA | 数十 ~ 数百 tok/s | 全部在显存 | 转述公开报告值 |

**核显和 CPU 差 5% 左右，这不是配置问题，是硬件结构决定的**——Xe 与 CPU 共享同一条内存带宽。**核显的价值不在「更快」，而在「把模型搬进显存、让出 CPU」。**

## 🧭 五份笔记的共同结论

1. **先把服务启动方式搞对，再谈优化。** `/api/ps` 的 `size_vram` 是你唯一需要盯的字段——它一个值就能告诉你核显到底用上没有。
2. **核显 ≈ CPU，不是 GPU。** 共享内存带宽决定了它们在同一档。想快只能换机器或换更小的模型。
3. **量化的甜点是 Q4_K_M。** 想要更高质量上 Q6_K / Q8_0，**不要低于 Q4**——低于 Q4 后质量掉得比速度涨得快。
4. **Ollama vs vLLM 的选择取决于并发，不是速度。** 单请求场景两者几乎没差别。
5. **上下文长度看服务端生效值，不看模型元信息。** `context_length: 262144` 不等于你能用 256k；被静默截断是最难查的一类问题。
6. **思考 token 是纯开销，且按标准速率计费。** 做端到端延迟和成本对比时必须计入。
7. **本地模型的价值边界是清楚的**：数据不出网、批量简单任务、不想花钱。**复杂推理上不要指望它。**

## ⚠️ 关于本章数据的性质

- [`01`](./01-本机部署实战-Ollama在无独显笔记本上的实测.md) 与 [`03`](./03-思考模型与本地推理的工程问题.md) 中的速度与 token 数是**作者本机实测**（2026-11-12 / 2026-11-14，华为 MateBook / i5-13500H / Intel Iris Xe 核显 / 31.7 GB RAM / Windows 11，Ollama 0.40.16，模型 qwen3:4b / Q4_K_M）。
- [`02`](./02-GGUF量化与推理后端选型.md) 中的量化档位体积为**按参数量的估算值**，后端特性为**转述自 llama.cpp / Ollama / vLLM 官方文档**；不同模型对量化的敏感度差别很大，**具体模型请以自己的实测为准**。
- [`04`](./04-本地模型的对齐边界.md) 中的拒绝行为矩阵是**本机 4B 模型的实测**，**与同系列更大模型的行为不可互相外推**——对齐行为随模型规模、训练配方、版本迭代而变。
- [`05`](./05-把本地模型接进RAG与Agent.md) **不新增仓库代码**，只给出接入设计与需要改动的位置；引用的 `code/agentkit/` 实现为仓库现状。
- **本机绝对路径、设备标识、网络信息已按公开分级脱敏。**
- 本仓库只收录研究笔记，**不收录任何第三方模型权重文件**。模型权重与相关工具均归属各自作者，请遵循其各自许可证。
