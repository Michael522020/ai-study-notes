## J. 高频易混词

| 容易混淆 | 区别 |
|---|---|
| **精确率 / 召回率** | 精确率 =「查出来的里有多少是对的」；召回率 =「该找出来的找出来多少」 |
| **IoU / mIoU** | IoU 是单个框/区域的交并比；mIoU 是多个类别/数据集的平均 |
| **AP / mAP** | AP 是单个类别单个 IoU 阈值下的 PR 曲线面积；mAP 是平均 |
| **召回 / 检索召回率** | 前者是「检测出多少目标」；后者是「检索到多少相关文档」 |
| **稠密检索 / 稀疏检索** | 稠密 = 稠密向量（语义）；稀疏 = 稀疏向量（词项） |
| **Bi-Encoder / Cross-Encoder** | Bi 独立编码（快，用于召回）；Cross 联合编码（准，用于重排） |
| **Prompt / Context / Instruction** | Prompt 是给模型的总输入；Context 是其中的资料部分；Instruction 是其中的指令部分 |
| **RAG / GraphRAG** | RAG 是通用范式；GraphRAG 是用知识图谱解决全局问题的具体方案 |
| **NMS / NMS-free** | NMS-free 是训练时用一对一匹配免除后处理去重 |
| **Anchor-based / Anchor-free** | 是否依赖预设的先验框 |
| **蒸馏 / 微调** | 蒸馏是让小模型学大模型的行为；微调是用数据训练模型 |
| **PTQ / QAT** | PTQ 训练后量化（快，有损）；QAT 量化感知训练（慢，精度高） |
| **预训练 / 继续预训练 / 微调** | 预训练 = 通用语料打底座；继续预训练 = 用领域语料继续跑自回归目标（改语言分布）；微调 = 监督信号改行为 |
| **SFT / 偏好对齐** | SFT 学「该怎么做」；偏好对齐（RLHF/DPO）学「哪种做法更好」 |
| **DPO / RLHF** | DPO 离线、无需奖励模型与采样；RLHF 在线、需 RM + PPO，上限更高但不稳 |
| **LoRA / Adapter / Prefix-Tuning** | 都是 PEFT；LoRA 可无损合并进基座（推理零开销），Adapter / Prefix 合并困难且有推理开销 |
| **LoRA / GaLore** | LoRA 改权重表示（低秩分解）；GaLore 改优化过程（梯度低秩投影），两者正交可叠加 |
| **rank r / alpha** | 有效缩放系数是 $\alpha/r$，不是 alpha；调 r 时应同比例调 alpha |
| **全参微调 / QLoRA** | 全参 = 全部权重可训，显存 16 bytes/param；QLoRA = 4bit 基座 + 少量 adapter，可训大模型 |
| **PPL / BPB** | PPL = exp(NLL)，跨 tokenizer 不可比；BPB 做了字节归一，跨 tokenizer 可比 |
| **Bot / Agent / Super Agent** | 按「事情怎么算做完」区分：用户觉得可以 / 产出了一份东西 / 通过了验收标准 |
| **工作流 / Agent** | 工作流的路径由代码预先确定；Agent 的路径由模型在运行时决定 |
| **单次调用 / Agent** | 只有一次请求、格式固定 → 单次调用，不要上 Agent |
| **缓存 / 压缩** | 缓存优化「不变的前缀」；长对话的瓶颈是「增长的后缀」，要靠压缩 |
| **预算（成本）/ 预算（token）** | 前者是美元上限；后者是 task_budget 的 token 上限（beta，最小 20,000） |
| **屏蔽 / 去标识** | 屏蔽是替换成占位符（保留结构、不可还原）；去标识是不可逆的匿名化 |
| **拒答 / 转人工** | 拒答是模型不给答案；转人工是流程移交，状态是 `needs_human` |
| **预填充 / 解码** | 预填充处理输入 prompt，算力密集；解码逐 token 生成，显存带宽密集 |
| **总参数 / 激活参数** | MoE 的显存按**总参数**算，算力按**激活参数**算 |
| **算子层优化 / 架构层改动** | 算子层改计算顺序、数学不变、不用重训；架构层改模型定义、**等于换模型** |
| **精确注意力 / 近似注意力** | FlashAttention 是**精确**的（数学不变）；线性/稀疏注意力才是近似的 |
| **无损优化 / 有损优化** | 投机解码、PagedAttention、连续批处理是无损的；KV 淘汰、量化是有损的 |
| **提示缓存 / 语义缓存** | 提示缓存复用**相同前缀**（要前缀逐字一致）；语义缓存按意图匹配（可能命中错误内容） |
| **词表大小 / 上下文长度** | 词表决定「同样文本占多少 token」；上下文长度是「最多能塞多少 token」 |
| **提示注入 / 越狱** | 注入改的是**行为**（做不该做的事）；越狱改的是**内容策略**（说不该说的话） |
| **直接注入 / 间接注入** | 直接 = 攻击者对模型说话；间接 = 攻击者把指令藏在**模型会读到的地方**，受害者自己触发 |
| **误报 / 漏报** | 误报 = 正常内容被当成攻击；漏报 = 攻击没被识别。**业务上误报更致命** |
| **污点确认 / 危险 API 出现** | 前者 = 数据**确实**可控地流到危险点；后者 = 只看到危险 API 被调用 |
| **成员推断 / 模型反演** | 成员推断问「在不在训练集」；模型反演要「还原训练数据本身」 |
| **检索层过滤 / 应用层过滤** | 应用层过滤 = 无权数据**已经进了上下文**；检索层过滤 = 无权数据根本不进来 |
| **沙箱 / 权限控制** | 沙箱限制**爆炸半径**（做了坏事出不去）；权限控制决定**能不能做**坏事 |
| **合规要求 / 合规实现 / 合规证据** | 要求 = 条款；实现 = 工程动作；证据 = 能证明做对了的东西（**三者缺一不可**） |
| **5G-A / 6G** | 5G-A 是 5G 的增强（Rel-18~20）；6G 是 IMT-2030（Rel-21 起）。**2026 年商用的是 5G-A** |
| **Pre-6G / 6G** | Pre-6G 是商用前的超前验证网（试验性质）；6G 是标准与商用体系 |
| **空口时延 / 端到端时延** | 空口只算无线段；端到端含采集、传输、边缘与应用，**差一个数量级** |
| **探测概率 / 虚警率** | 探测概率是「找得到」，虚警率是「误报多」；**感知系统必须成对给，单报探测概率无意义** |
| **通感一体 / 雷达** | 通感一体用通信信号感知，目标画像更丰富但分辨率低于专用雷达；**两者常做多模融合，不是替代关系** |
| **AI 原生 / AI + 网络** | 「AI +」是给网加 AI 模块；AI 原生是**网络按 AI 的方式被设计**（模型即网元、意图驱动） |
| **网络切片 / 感知切片** | 网络切片切的是连接资源；感知切片切的是**感知资源（空域+精度+目标类型）** |
| **网络市场 / 核心产业 / 带动产出** | 三种市场规模口径，**可差 7 倍**；引用前必须问清是哪一个 |
| **构建缓存 / KV Cache** | 构建缓存缓存的是「编译产物」（LTAR），按**源码输入哈希**寻址、跨机器共享；KV Cache 缓存的是「注意力键值」，按**上下文位置**索引、单机单会话 |
| **字节压缩 / 模块合并** | 字节压缩（zstd/xz）减小单个文件；对 Lean 项目更有效的是**减少模块数**——每省一个模块就省一份 tar header，也让导入图更细 |

## L. AI 落地方法论与 FDE

### L.1 流程与阶段

| 缩写 / 术语 | 全称 / 中文 | 说明 |

| **Drift** | 漂移 | 输入/输出分布随时间偏离训练分布 |

## Q. 前端安全与代码审计




> 详见 [`../05-逆向分析工具链/02-静态代码分析工具链-自建污点追踪嗅探器.md`](../05-逆向分析工具链/02-静态代码分析工具链-自建污点追踪嗅探器.md)

| 术语 | 全称 / 说明 |
|---|---|
| **污点分析 / Taint Analysis** | 追踪「不可信输入」是否流到「危险汇聚点」的静态分析方法；**是区分「用了危险 API」和「真的可利用」的关键** |
| **Source / Sink** | 污点分析的起点（`location.search`、DOM 存储、`postMessage`）与终点（`innerHTML`、`eval`、`document.write`） |
| **强污点 / 弱污点** | 来源可明确判定为强污点；形参名可疑等不确定来源按弱污点处理并**降低置信度** |
| **掩码 / masking** | 把注释与字符串字面量的**内容**换成空格，**保持长度与换行不变**；这样偏移量与原文件 1:1 对应，行列号不会漂 |
| **iter_matches / iter_raw** | 掩码后视图（只看代码结构）与原始源码视图（要看字面量**内容**）；**用错视图会让规则静默失灵** |
| **作用域索引** | 变量所属函数的索引；**污点只在同一函数作用域内传播**，防止同名变量互相污染 |
| **置信度 / confidence** | 一条规则结论的可信程度；没有置信度的报告只是一堆排序不明的告警 |
| **误报 / 漏报** | 假阳性（报了你不需要修的）与假阴性（该报没报）；**漏报比误报危险得多** |
| **对照组 / 回归基线** | 靶页面里刻意写的「规范写法」片段；规范页面必须**零发现**，改规则后必跑 |
| **过程内分析 / 过程间分析** | 只在单个函数内追踪污点 vs 跨调用图传播；静态嗅探器通常只做前者，弱污点是对跨函数情形的近似补偿 |
| **DOM XSS** | 通过 DOM API 注入脚本；`innerHTML`、`document.write`、`eval` 是典型 sink |
| **CSRF / CSP / CORS** | 跨站请求伪造 / 内容安全策略 / 跨源资源共享 |
| **HSTS / nosniff** | 强制 HTTPS 响应头 / 禁止浏览器 MIME 类型嗅探的响应头 |
| **Referrer-Policy / Permissions-Policy** | 控制 Referer 泄露与浏览器能力授权的响应头 |
| **ReDoS** | Regular expression Denial of Service，灾难性回溯导致正则超时 |
| **原型污染** | 修改 `Object.prototype` 影响所有对象；常见于未校验的 JSON 合并 |
| **CWE / OWASP Top 10** | 通用弱点枚举编号 / OWASP 十大风险分类；静态规则的标准元数据 |
| **无头渲染** | 用无头浏览器执行页面 JS 后再扫描；只能补上浏览器里跑出来的那部分 |
| **--fail-on** | 指定级别及以上即以非零退出码结束的 CI 开关；**没有它，静态检查进不了 CI** |

| 缩写 / 术语 | 全称 / 中文 | 说明 |
