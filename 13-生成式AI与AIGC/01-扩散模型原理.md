# 扩散模型原理

> **核心问题**：文生图到底在算什么？为什么「去噪」能生成图像？CFG 在放大什么？

---

## 0. 一句话直觉

**扩散模型的思路是反过来的：把「从噪声画出图」这件难事，换成「把图一步步擦成噪声」这件易事。**

```
训练： 真实图 x₀  --加噪-->  x_t  --加噪-->  ...  --加噪-->  x_T（纯噪声）
                                        （每一步都能学会「怎么往回擦一步」）

推理：  x_T（纯噪声）  --去噪-->  x_{T-1}  --去噪-->  ...  --去噪-->  x₀（图像）
```

**训练时只需学一个函数**：`噪声预测器 ε_θ(x_t, t, 条件)`——
告诉它「当前这个带噪图像，噪声长什么样」。

**推理时**用同一个网络反向走一遍，就得到图像。

> **类比**：像一张被墨水浸透的照片，
> 训练是教网络「怎么擦掉一层墨」，推理是从完全黑的状态开始，一层层擦出照片。

## 1. 两个数学框架

### 1.1 DDPM（去噪扩散概率模型）

**前向过程**（固定、无参数）：

```
q(x_t | x_{t-1}) = N(√(1-β_t) · x_{t-1},  β_t · I)
```

**关键性质：可以一步跳到任意 t**（不用一步步加噪）：

```
q(x_t | x_0) = N(√(ᾱ_t) · x_0,  (1-ᾱ_t) · I)

其中 ᾱ_t = ∏_{s=1}^{t} (1-β_s)
```

**这是训练能高效进行的关键**——不需要模拟整个加噪过程。

**反向过程**（要学）：

```
p_θ(x_{t-1} | x_t) = N(μ_θ(x_t, t), Σ_t)
其中 μ_θ 由 ε_θ(x_t, t) 推出
```

**训练目标**（简化的噪声预测 MSE）：

```
L = E_{x₀, ε, t} [ ‖ ε - ε_θ(√ᾱ_t · x₀ + √(1-ᾱ_t) · ε, t) ‖² ]
```

> **注意这个损失形式**：
> 训练时**同时随机采一个 t**，
> 所以一个模型学会**所有噪声级别**的去除——
> 这就是它能「从纯噪声一步步走回来」的原因。

### 1.2 DDIM（去噪扩散隐式模型）

**DDPM 的问题**：推理要跑 T 步（通常 50~1000 步），太慢。

**DDIM 的改动**：把反向过程改成**确定性的**，于是可以用**非马尔可夫**的跳跃过程：

```
从 x_t 直接跳到 x_s（s < t），只采样一次噪声 ε
```

**关键收益**：
- **采样步数可以自由减少**（20~50 步就能出图）
- **同一个噪声种子，采不同的步数会得到不同质量的同构图**（便于调参）

> **DDIM 是今天所有「少步采样」工作的起点。**

## 2. 潜空间：为什么不在像素空间做

**直接在像素上做扩散，UNet 要处理 3×1024×1024 的张量，极慢。**

**Latent Diffusion（LDM / Stable Diffusion）** 的做法：

```
像素 x
  ↓ VAE Encoder（8 倍下采样）
潜变量 z (4 × 128 × 128)
  ↓ 在潜空间做扩散 ★ 便宜 48 倍
  ↓ VAE Decoder
像素 x̂
```

| 项 | 像素空间 | 潜空间（512×512） |
|---|---|---|
| UNet 输入张量 | 3×512×512 | 4×64×64 |
| 相对计算量 | 1× | **~1/48** |
| 显存 | 高 | 低 |
| 细节损失 | 无 | **有**（VAE 重建误差） |

> **潜空间是扩散模型能跑起来、也能在消费级显卡上跑的关键。**
> 它的代价是 **VAE 重建会损失高频细节**——
> 这也解释了为什么 SDXL 之后大家开始用 **VAE 升级 / 微调 VAE / 换更高分辨率 VAE**。

### 2.1 VAE 的两个损失项

```
L_VAE = 重建损失 + KL 散度
         ↑ 像素级相似    ↑ 让潜空间接近标准正态（方便加噪）
```

**KL 项的权重**（`kl_weight`）是个实际调参点：
- 太小 → 潜空间不规整，扩散难学
- 太大 → 重建质量下降

> **实用提示**：用别人训好的 VAE 时，**不要动 `kl_weight`**——
> 它和 VAE 权重是配套的。

## 3. UNet：主干网络

**扩散模型的主体是 UNet**，但和分割的 UNet 有几处关键差异：

| 部件 | 分割 UNet | 扩散 UNet |
|---|---|---|
| **输入通道** | 3（RGB） | **4**（潜变量） |
| **时间嵌入** | 无 | **有**（ sinusoidal + MLP） |
| **条件注入** | 无 | **有**（cross-attention） |
| **输出** | 分割图 | **预测噪声**（同 4 通道） |
| **归一化** | BatchNorm | **GroupNorm**（batch size 通常很小，BN 不稳） |
| **注意力位置** | 编码器 + 解码器 | 通常**只在低分辨率层**（省显存） |

### 3.1 时间嵌入与条件注入

```
时间 t → sinusoidal embedding → MLP → 向量
                                    ↓
                           加到每个 block 的特征上（AdaLN 或 scale+shift）
                                    ↓
文本条件（CLIP embedding）→ cross-attention → 注入每个 block
```

**「文本条件」与「时间条件」走两条不同的路**：
- 时间 → **加法**（改变特征的整体尺度）
- 文本 → **注意力**（决定「关注哪些 token」）

### 3.2 文本编码器

| 模型 | 文本编码器 | 说明 |
|---|---|---|
| **SD 1.x** | OpenCLIP ViT-L/14 | 512 token 上限 |
| **SD 2.x** | OpenCLIP ViT-H/14 | 1024 token 上限 |
| **SDXL** | CLIP-L + OpenCLIP-bigG（双编码器） | 分别处理文本与池化文本 |
| **SD 3.x / Flux** | **T5-XXL + CLIP-L**（双文本编码器） | T5 负责长文本理解 |

> **SD 3 / Flux 用双文本编码器是一个重要趋势**：
> CLIP 的 77 token 限制对长提示词是硬伤，
> T5 提供更细的语义。但双编码器让显存与延迟都上升。

## 4. Classifier-Free Guidance（CFG）

### 4.1 它在做什么

**CFG 把「有条件的预测」和「无条件的预测」混合，用差值放大条件的影响：**

```
ε_guided = ε_uncond + s · (ε_cond - ε_uncond)
             无条件   ↑ scale    ↑ 条件与无条件的差
```

**直觉**：
- `ε_uncond` 是「随便画」
- `ε_cond` 是「按提示词画」
- **两者的差** = 「提示词把这个方向推动了多少」
- 乘以 `s` 再加回去 = **把提示词的作用放大 s 倍**

### 4.2 代价与参数

| 项 | 说明 |
|---|---|
| **推理成本** | **每步要跑两次前向**（cond + uncond），**慢一倍** |
| **scale 太小**（1~3） | 画面平淡、不贴提示词 |
| **scale 太大**（>12） | **过饱和、颜色爆炸、结构崩坏** |
| **常用值** | 7.5（SD 1.5）/ 5~7（SDXL）/ 3.5~5（Turbo） |

> **CFG 的本质是「用两倍算力换可控性」**。
> 而且它在**每一步**都要付这个代价——所以步数少时 CFG 的相对开销更大。

### 4.3 常见误解

| 误解 | 事实 |
|---|---|
| 「CFG=0 就没有条件」 | CFG=1 就是纯条件预测（不加倍） |
| 「Turbo / Lightning 不用 CFG」 | 它们用**小 scale（1~2）** 的 CFG，仍需两次前向（除非用蒸馏模型完全去掉 uncond 分支） |
| 「提高 CFG 能提升质量」 | **不能**。它放大的是「对提示词的贴合度」，过大会破坏图像自然度 |

## 5. 训练与推理的完整流程

### 5.1 训练一个扩散模型

```
1. 准备数据（图 + 文本 caption）
2. 文本 → CLIP/T5 → 文本 embedding
3. 图像 → VAE Encoder → 潜变量 z₀
4. 随机采 t ∈ [1, T]
5. 采随机噪声 ε ~ N(0, I)
6. 构造带噪潜变量：z_t = √ᾱ_t · z₀ + √(1-ᾱ_t) · ε
7. UNet 预测噪声，算了 MSE
8. 反向传播
```

**工程要点**：

| 要点 | 说明 |
|---|---|
| **caption 质量决定一切** | SD 的图和 prompt 是**逐图配对**训练的，caption 不准 → 图和 prompt 对不上 |
| **分辨率桶** | 不同分辨率要分组训练，或用 bucketing 避免拉伸 |
| **预训练权重** | **不要从零训 UNet**；从 SD 1.5 / SDXL 的权重继续训 |
| **显存** | 8×A100 训 SDXL 全量；LoRA 4~8 卡；**推理 8GB 显存即可（512px）** |

### 5.2 推理流程

```
1. 文本 → CLIP/T5 → embedding
2. 随机（或固定）种子 → 初始潜变量 z_T（纯噪声）
3. for t in 采样步数:
     ε_cond   = UNet(z_t, t, text_emb)
     ε_uncond = UNet(z_t, t, null_emb)     ← CFG 需要
     z_{t-1}  = 采样器更新(z_t, ε_guided, t)
4. z₀ → VAE Decoder → 图像
```

**关键**：
- **种子固定 → 同一张图可复现**（做对比实验的基础）
- **步数**与**CFG scale**是两个独立的旋钮
- **采样器**（见 [`02`](./02-采样器与加速.md)）决定同样步数下的质量

## 6. 工程结论

1. **扩散是「学去噪」而不是「学生成」**——把难问题换成易问题，这是它能 work 的根本原因。
2. **前向过程可以一步跳到任意 t**（闭式解），这是训练能高效进行的关键。
3. **训练时随机采 t**，所以一个网络同时学会所有噪声级别。
4. **潜空间（VAE + 8 倍下采样）让计算量降到 1/48**——这是扩散能跑在消费级显卡上的原因；
   代价是 **VAE 重建损失高频细节**。
5. **CFG 用两倍算力换可控性**：把「条件与无条件的差」放大 s 倍。
   **提高 CFG 不会提升画质，只会提升「贴提示词」的程度**，过大会崩坏。
6. **时间条件走加法、文本条件走注意力**——两条路，别混。
7. **caption 质量决定模型质量**（SD 的图与 prompt 是配对训练的）。
8. **不要从零训 UNet**，永远从预训练权重继续。
