# 13 · 生成式 AI 与 AIGC

> **从「模型会画」到「业务能用」：扩散原理、加速、可控、编辑、视频、合规。**

前面各主线讲的是**理解**（看、检索、推理、编排）。
这条讲**生成**——但重点不在「怎么生成」，而在**「怎么生成得可控、怎么算清成本、怎么合规」**。

**它的核心判断只有一句**：

> **生成的落地难点从来不是「能不能生成」，而是「能不能稳定地生成可用的东西，
> 并说清楚它是谁生成的、能不能商用」。**

## 💰 成本的正确单位

```
一次可用图成本 = 单次生成耗时 × GPU 单价 ÷ 可用率
```

| 可用率 | 相对成本 | 场景 |
|---|---|---|
| 30%~70% | **1×** | 批量模板化（最省） |
| 5%~20% | 4~12× | 精确控制 + 人工修 |
| 1%~5% | 20~40× | 提示词生成 + 人工挑选 |
| **< 1%** | **100×** | 端到端自动化（几乎不可行） |

> **可用率从 5% 降到 1%，成本涨 5 倍。**
> **这比任何模型优化都重要**——
> **提高可用率（更好的控制 + 更好的工作流）是最划算的优化。**

## 🎛️ 控制手段分工

| 要控制什么 | 用什么 | 训练成本 |
|---|---|---|
| **结构**（边缘/深度/姿态/分割） | **ControlNet** | **零**（现成权重） |
| **风格 / 参考图** | **IP-Adapter** | 零 |
| **具体概念**（角色/产品/画风） | **LoRA** | **有** |
| **局部区域** | **遮罩 + Inpainting** | 零 |
| **prompt 的作用范围** | 区域提示 | 零 |

> **每加一个条件，就降一点其他条件的强度**——
> 三个条件都开满，结果就是「谁都不满足」。

## 🎬 视频落地：关键帧 + 插帧

**这是当前生成视频最务实的工作流**：

```
① 图像生成模型产出关键帧（每帧可控）
        ↓
② 帧间插帧（RIFE / FILM 等专用模型）—— 快、稳、无闪烁
        ↓
③ 时序平滑 + 剪辑
```

| 维度 | 关键帧 + 插帧 | 直接视频生成 |
|---|---|---|
| **可控性** | **极高**（每帧可控） | 低 |
| **一致性** | **高** | 中 |
| **成本** | **低** | 高 |
| **时长** | **想多长就多长** | 受模型限制 |

> **它把「视频生成」的难题，转成了「图像生成 + 插帧」两个有成熟解法的子问题。**

## ⚖️ 合规：三个必须先问的问题

```
① 底模的许可证允许商用吗？
② 训练素材（你的图、LoRA 的训练图）有商用授权吗？
③ 生成的内容会被用于什么场景？
```

> **这三个的交集才决定「能不能商用」。**
> **只看底模许可是最常见的误判。**

| 层次 | 关键提醒 |
|---|---|
| **底模许可** | 订阅 ≠ 商用授权；有些模型有**营收门槛**；RAIL 类附带了「你不能用来侵权」的使用限制 |
| **素材版权** | **用网上扒的图训 LoRA 再商用 = 典型侵权来源** |
| **生成物** | 纯 AI 生成通常**不受版权保护**（不独占）；但**商标/肖像/著作权依然适用** |
| **内容标识** | 显式 + 隐式；**隐式会被平台剥掉** → 要叠不可见水印 |
| **输出责任** | **责任在使用者**，不能说「是模型生成的」 |

## 💡 工程结论（浓缩版）

1. **扩散是「学去噪」**——把难问题换成易问题，这是它能 work 的根本原因。
2. **潜空间让计算量降到 1/48**，这是扩散能跑在消费级显卡上的原因；
   代价是 VAE 重建损失高频细节。
3. **CFG 用两倍算力换可控性**，放大的是「对提示词的贴合度」——
   **提高 CFG 不会提升画质**，过大会崩坏。
4. **默认用 DPM-Solver++(2M Karras)**，10~20 步；调参**一次只改一个变量、固定种子**。
5. **SD1.5 出高分辨率要走 hires fix 工作流**（512 → 放大 → 低 strength 二次 img2img）。
6. **分辨率对画质的影响 > 采样器**。
7. **结构用 ControlNet、风格用 IP-Adapter、概念用 LoRA、局部用遮罩**；
   **ControlNet 的 Zero Conv 让它可插拔**。
8. **角色 LoRA 的素材必须覆盖角度/表情/光线**；caption 要短，让触发词与人强绑定。
9. **不要用少步模型（Turbo/LCM）的出图去训练扩散模型**——会放大「蒸馏指纹」。
10. **视频的难点在时序与运动，不在画质**；落地走**关键帧 + 插帧**。
11. **成本以「一次可用图」计**；**提高可用率是最划算的优化**。
12. **能不能商用 = 底模许可 ∩ 素材版权 ∩ 使用场景**；订阅 ≠ 商用授权。
13. **生成记录（prompt/seed/全部参数/输出哈希/审核结果）不能省**——
    它是复现、回溯与合规的共同基础。
