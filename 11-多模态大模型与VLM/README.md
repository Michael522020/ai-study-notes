# 11 · 多模态大模型与 VLM

> **让模型「看见」：从视觉编码器到业务落地的完整链路，以及一条更省的路线。**

前面各主线里，视觉是**独立**的（01/02 讲检测），语言是**独立**的（03/10 讲 LLM 与检索）。
这条主线讲**两者怎么接起来**——以及**什么时候不该接**。

**它的核心判断只有一句**：

> **VLM 的不可替代性在于「开放式视觉理解」。
> 其余任务用 VLM 往往是「用大炮打蚊子」——更贵、更不准、更不可控。**

## 💰 一张表看清代价

**以 Llama-3-8B（GQA, 128 KiB KV/token）为例。**

| 场景 | 视觉 token | 序列总长 | **单图 KV Cache** |
|---|---|---|---|
| 全图 224px | 257 | 357 | 44 MB |
| 全图 336px | 577 | 677 | 85 MB |
| **切片 2×2 + 全局** | 2880 | 2980 | **373 MB** |
| 动态 1024 | 1024 | 1124 | 141 MB |
| 动态 4096 | 4096 | 4196 | **525 MB** |
| **区域级（Set-of-Mark）** | **50** | 150 | **19 MB** |

> **跨度 50 ~ 2880，是 57 倍；而效果提升远没有 57 倍。**
> **视觉 token 数量级决定成本，不是决定质量。**

## 🎯 四种落地形态（按成本与可靠性）

| 形态 | 做法 | 成本 | 可靠性 | 适用 |
|---|---|---|---|---|
| **① 专用模型** | 检测器/分类器直接出结果 | **最低** | **最高** | 固定类目、固定字段 |
| **② OCR + 文本 LLM** | OCR 转文本 → 文本 LLM | 低 | 高 | **文档、票据、表格** |
| **③ 检测器 + 文本 LLM** | 结构化事件 → 文本 LLM | 中 | 高 | **工业质检、农业、监控** |
| **④ VLM 直接看图** | 图像 → VLM 回答 | **最高** | 中 | **开放式视觉理解** |

> **③ 是最被低估的形态**——
> 它在「需要理解」和「要可控可审计」之间取到了最好的平衡，
> 而且**这正是本库 04 边缘部署主线在做的事**。

## 📡 端侧：算三笔账

| 设备 | 能跑什么 | 判断 |
|---|---|---|
| **ESP32-P4** | 专用小 CNN（检测/分类） | **不能跑 LLM，更不能跑 VLM** |
| **RK3588S** | 0.5~2B 量化小模型（**很慢**） | 能跑极小的，多模态不现实 |
| **手机/平板** | 1~3B 量化 VLM（几秒级） | 可做离线助手 |
| **SBC** | CPU 量化 LLM（个位数 tok/s） | 勉强 |

> **结论**：**端侧跑完整 VLM 不可行**。
> **正确架构是「端侧检测 → 结构化事件 → 云端文本 LLM/VLM 理解」**——
> 显存、延迟、可审计、可回溯、隐私、扩展性**六项全面占优**。

## 🔍 评测的两个关键动作

| # | 动作 | 为什么 |
|---|---|---|
| **1** | **盲测对照** | 不给图跑一遍纯文本模型。**它能答对的题就没测到视觉能力**（MMStar 的核心方法） |
| **2** | **分层指标** | 整体 / 细节 / OCR / 定位 / 计数 / 空间 / 幻觉 / 拒答，各层单独定阈值 |

> **没有盲测对照的 VLM 评测分数，基本没有参考价值。**

## 💡 工程结论（浓缩版）

1. **视觉 token 数 = (H/P)×(W/P)+1**，分辨率翻倍 token 变 4 倍。
2. **Projector 用 MLP 就够**（现代开源 VLM 的共识）；视觉 token 数由编码器与分辨率决定。
3. **跨度从 50 到 2880 是 57 倍，效果提升远小于此**——
   **token 数量级决定成本，不是决定质量**。
4. **边际收益递减**：注意力稀释 + 冗余 + 位置效应，三者共同作用。
5. **KV Cache 是主导成本**（2880 token ≈ 373 MB）；**多图多轮必须缓存视觉特征**。
6. **prefill 是超线性的**（O(S²)），token 翻倍 prefill 慢 4 倍。
7. **文档类场景先 OCR**：200 页 PDF 能省 4~5 倍成本，且数字更准。
8. **四类数据缺一不可**（图文对/指令/偏好/**纯文本**），**纯文本防遗忘**不能省。
9. **数据质量 > 数据数量**（LLaVA-1.5 实证）；领域微调要保留通用数据作锚。
10. **「解冻视觉编码器最后 1/4 层」性价比最高**；**训推 token 预算必须一致**。
11. **LoRA 省不掉激活显存**，而激活显存由序列长度决定。
12. **端侧跑完整 VLM 不可行**；**「检测器 + 结构化事件 + 云端 LLM」六项占优**。
13. **视觉特征缓存**是 VLM 场景性价比最高的优化。
14. **评测必须有盲测对照**，否则测的是语言先验不是视觉能力。
15. **VLM 只用在真正需要「开放视觉理解」的地方**。
