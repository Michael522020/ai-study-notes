# 评测与落地

> **核心问题**：VLM 怎么评？公开基准能信吗？业务场景该选哪种形态？

---

## 0. 评测的三个层次

```
① 感知能力    能不能看见？   → OCR、定位、计数、颜色、属性
② 认知能力    能不能想明白？ → 推理、常识、多步
③ 实用性      能不能干活？   → 业务任务的成功率
```

> **公开基准主要测 ①②，业务落地看 ③。**
> **一个在 MMMU 上分数很高的模型，在你的业务上可能完全不能用。**

---

## 1. 主要基准速查

| 基准 | 测什么 | 语言 | 规模 | 局限 |
|---|---|---|---|---|
| **MMBench** | 综合多任务 | 中/英 | 数千 | 题目偏「看图说话」，与业务距离远 |
| **MMMU** | 大学级多学科（图文推理） | 英 | 11.5K | **难度高但题型窄**，多选题为主 |
| **MMMU-Pro** | MMMU 升级版 | 英 | — | 更严格，选项更多 |
| **SEED-Bench** | 综合 + 生成 | 中/英 | 19K | 覆盖面广，难度中等 |
| **MME** | 综合评价（含幻觉） | 中/英 | — | 用 yes/no 打分，**易被「猜对」污染** |
| **MathVista** | 数学视觉推理 | 英 | 6.4K | **对纯文本 LLM 也很友好**，视觉必要性不足 |
| **OCRBench** | OCR 能力 | 中/英 | 1K | **测的是 OCR，不是理解** |
| **DocVQA** | 文档问答 | 英 | 12.6K | 单页文档 |
| **ChartQA** | 图表问答 | 英 | 18K | **图表是合成的**，与真实业务图表有差距 |
| **InfoVQA** | 信息型 VQA | 英 | 28K | 同上 |
| **TextVQA / OCR-VQA** | 场景文字 | 英 | — | 场景文字，非文档 |
| **POPE** | **物体幻觉** | 英 | 9K | yes/no 格式，有「蒙对」空间 |
| **AMBER** | 幻觉（生成式） | 中/英 | — | 覆盖全面但判定依赖 LLM 判官 |
| **MMStar** | 综合（**经过视觉必要性过滤**） | 中/英 | 1.5K | **规模小**，但方法论最正确 |
| **BLINK** | 人类直觉级视觉任务 | 英 | — | **刻意设计成「人容易、模型难」** |
| **RealWorldQA** | 真实世界场景 | 中/英 | — | 样本量偏小 |

### 1.1 MMStar 值得单独说

**它的核心贡献是一个「过滤」方法**：

```
一道题如果「不给图也能答对」（靠语言先验猜），
   → 它没有测到视觉能力 → 剔除
```

**这个方法论比任何具体基准都重要**：
**你自己的评测集也必须做这个过滤**，否则你测的是模型的语言先验，不是视觉能力。

### 1.2 公开基准的三个通病

| 通病 | 表现 | 对策 |
|---|---|---|
| **视觉必要性不足** | 不看图也能猜对 | **盲测对照**（见 §4） |
| **题型与业务距离远** | 「图中是什么风格的艺术品」 | **自建业务集** |
| **评分方式被「猜对」污染** | yes/no 题随机猜对率 50% | 用**生成式 + 判官**或**多选题 + 干扰项** |

> **「是/否」类基准（MME、POPE）要特别小心**：
> 一个什么都不看、只回答「是」的模型，在这类基准上能拿很高的分。

## 2. 幻觉：VLM 特有的失败模式

**LLM 会编故事，VLM 会「看到」不存在的东西。**

| 类型 | 例子 | 检测方法 |
|---|---|---|
| **物体幻觉** | 图里只有 2 个苹果，回答「3 个」 | POPE、计数题 |
| **属性幻觉** | 说一个不存在的颜色 | 属性题对照 |
| **关系幻觉** | 说「在左边」，实际在右边 | 空间关系题 |
| **动作幻觉** | 编造图中发生的动作 | 描述 vs 人工标注对比 |
| **OCR 幻觉** | 把不存在的字读出来 | 逐字比对 |
| **背景幻觉** | 编造场景、天气、时间 | 结构化提问 |

### 2.2 幻觉的三个来源

| 来源 | 机制 | 对策 |
|---|---|---|
| **语言先验压过视觉** | 「图里有苹果」比「图里没有苹果」更可能 | 用「否定/不存在」类样本训练 |
| **视觉 token 不足** | 看不清 → 靠先验补 | 提高分辨率 / 区域级方案 |
| **训练数据里有幻觉** | 教师模型编的 caption 被学了 | 数据清洗 + 一致性检查 |

> **最有效的幻觉对策是「让模型学会说不知道」**——
> 这需要在训练数据里**大量加入「图里没有 X」的样本**，
> 并在推理时给一个明确的「允许拒答」提示。

## 3. 评测自己的业务：六步

```
① 定义任务形态        分类？抽取？问答？定位？计数？
② 收集真实样本        100~500 条起，含 bad case 与边界样本
③ 做「盲测对照」★     不给图，用纯文本模型跑一遍
④ 分层标注答案        整体 / 细节 / OCR / 定位 / 计数 / 空间 / 推理
⑤ 建基线              人工 / 规则 / 现有模型 / 纯文本 LLM
⑥ 定指标与阈值         每层单独定，不看总分
```

### 3.1 第 ③ 步：盲测对照（最重要的一步）

```python
def blind_baseline(samples, text_llm):
    """
    不给模型看图，只给文本问题（必要时给「通用描述」）。
    如果模型能答对，这道题就没有测到视觉能力。
    """
    blind_correct, blind_wrong = 0, 0
    for s in samples:
        # 故意不给图，只给问题；或给一个模糊的通用描述
        pred = text_llm.answer(s.question, no_image=True)
        if pred == s.answer:
            blind_correct += 1
        else:
            blind_wrong += 1
    return blind_correct / len(samples)
```

**结果怎么用**：

| 盲测正确率 | VLM 正确率 | 结论 |
|---|---|---|
| 低（<20%） | 高 | ✅ 这批题**有效测到了视觉能力** |
| 高（>60%） | 高 | ⚠️ 题目被语言先验覆盖了，**要么换题要么换指标** |
| 高 | 低 | ⚠️ **模型在真的用视觉**，且比语言先验差 → 是有效难题 |

> **没有盲测对照的 VLM 评测分数，基本没有参考价值。**

### 3.2 分层指标

| 层 | 指标示例 | 样本量建议 |
|---|---|---|
| **整体描述** | 人工评分（相关性/准确性/流畅度） | 50+ |
| **细节识别** | 准确率 / F1 | 100+ |
| **OCR** | **逐字准确率**（不是模糊匹配） | 50+ |
| **定位** | IoU / 点命中精度 | 100+ |
| **计数** | 精确匹配率（不是 IoU） | 50+ |
| **空间关系** | 准确率 | 50+ |
| **幻觉** | **幻觉率**（说错的比例） | 100+ |
| **拒答** | 正确拒答率 / 错误拒答率 | 50+ |

> **OCR 与计数必须用严格指标**：
> OCR 用逐字准确率（编辑距离），计数用精确匹配——
> **用模糊匹配会把幻觉藏起来。**

### 3.3 判官的选择

| 判官方式 | 优点 | 局限 |
|---|---|---|
| **人工** | 最准 | 贵、慢、主观 |
| **LLM-as-Judge** | 快、可扩展 | **必须先校准** |
| **规则/精确匹配** | 无偏、可复现 | 只适用结构化答案 |
| **混合** | 结构性用规则，开放性用判官 | **推荐** |

> **LLM-as-Judge 必须先校准**——
> 用一批人工标注的样本测判官本身的一致性，**校准后才敢用它的分数做决策**。
> 见 [`../12-AI落地方法论与FDE实战/06-案例拆解.md`](../12-AI落地方法论与FDE实战/06-案例拆解.md) §2.3。

## 4. 四种落地形态（按成本与可靠性递增）

| 形态 | 做法 | 成本 | 可靠性 | 适用 |
|---|---|---|---|---|
| **① 专用模型** | 检测器/分类器直接出结果 | **最低** | **最高** | 固定类目、固定字段 |
| **② OCR + 文本 LLM** | OCR 转文本 → 文本 LLM | 低 | 高 | **文档、票据、表格** |
| **③ 检测器 + 文本 LLM** | 结构化事件 → 文本 LLM 判断 | 中 | 高 | **工业质检、农业、监控** |
| **④ VLM 直接看图** | 图像 → VLM 回答 | **最高** | 中 | **开放式视觉理解** |

### 4.1 选型判据

```
问题需要「开放理解」吗？
  ├─ 不需要（固定类目/字段/计数）
  │     ├─ 类别是固定的 → ① 专用模型
  │     └─ 是文档/票据 → ② OCR + 文本 LLM
  └─ 需要（描述、推理、解释、跨图比较）
        ├─ 能用结构化信息替代吗？→ ③ 检测器 + 文本 LLM ★
        └─ 真的必须看图 → ④ VLM
```

> **③ 是最被低估的形态**：
> 它在「需要理解」和「要可控可审计」之间取到了最好的平衡。

### 4.2 四种形态的质量-成本象限

```
      可靠性高
          │
    ①专用  │  ②OCR+LLM
    ③检测器 │
          │
          │                    ④ VLM
          │                     （成本高）
          └──────────────────────────────→ 成本高
```

## 5. 三个行业的具体建议

### 5.1 工业质检

| 环节 | 建议 |
|---|---|
| **缺陷检测** | **① 专用检测器**（INT8 量化，端侧可跑） |
| **尺寸测量** | ① 专用模型 + 标定 |
| **缺陷原因分析** | ③ 检测器出事件 → 文本 LLM 结合工艺知识分析 |
| **工艺改进建议** | ③ + 检索（工艺文档 RAG） |
| **人工复核** | **必须**：AI 只做辅助标记，判定由质检员 |

> **不要让 VLM 直接判「这块料合不合格」**——
> 检测器 + 量化指标 + 人工确认，比 VLM 的直接判断更准、更可追溯、更便宜。

### 5.2 医疗影像

| 环节 | 建议 |
|---|---|
| **病灶分割 / 定量测量** | ① 专用模型（分割 + 量化指标） |
| **结构化报告生成** | ②/③：结构化数据 → 文本 LLM |
| **初步意见** | **不出具**。由医师判断 |
| **随访对比** | ① + ③（历史结构化数据对比） |

> **与 medplan 形态一致**：**AI 只做辅助标记与量化指标，不出具诊断结论**，
> 诊断结论由执业医师确认并电子签名。
> 这不是能力问题，是**责任问题**。

### 5.3 农业病虫害

| 环节 | 建议 |
|---|---|
| **虫体/病斑检测** | ① 专用检测器（**端侧可跑**，见 [`04`](../04-边缘部署与端侧AI/)） |
| **作物长势 / 环境参数** | ③ 结构化（传感数据 + 检测结果） |
| **农技建议** | ③/④：结构化 + 检索农技知识库 → 文本 LLM |
| **药剂建议** | **必须**：结合当地法规与植保手册，**AI 出建议，人签字** |

> **端云协同是农业场景的最优解**——
> 网络覆盖差、设备成本敏感、专家资源稀缺。

## 6. 常见错误

| 错误 | 表现 | 纠正 |
|---|---|---|
| **只看公开基准** | MMMU 高分就上业务 | **自建业务集 + 盲测对照** |
| **没有盲测对照** | 分数高但没测到视觉 | 第 ③ 步不可省 |
| **用 yes/no 题评测** | 蒙对率高 | 多选题带干扰项，或生成式 + 判官 |
| **OCR 用模糊匹配** | 幻觉被藏起来 | 逐字准确率 |
| **不测幻觉** | 上线后模型开始编 | 专设幻觉层 + 否定样本 |
| **不测拒答** | 模型什么都敢答 | 正确拒答率 + 错误拒答率 |
| **VLM 什么任务都用** | 贵、慢、不可控 | 按 §4 的判据选形态 |
| **不做影子运行** | 直接上线 | 见 [`../12`](../12-AI落地方法论与FDE实战/03-试点-影子-灰度-规模化.md) |
| **判官不校准** | 分数波动，无法决策 | 先校准再用 |

## 7. 工程结论

1. **公开基准测的是「感知 + 认知」，业务落地看「实用性」**——
   **MMLU 高分不等于业务能用**。
2. **MMStar 的「视觉必要性过滤」是本库最值得复用的评测方法**：
   **不给图也能答对的题，不算视觉题**。
3. **盲测对照是自己评测的第一道工序**，没有它，分数基本没有参考价值。
4. **yes/no 类基准要警惕「蒙对」**（随机 50%）；OCR 用逐字准确率，计数用精确匹配。
5. **幻觉要单独设层测**，且训练数据里要**大量加入「图里没有 X」的样本**。
6. **四种落地形态**：专用模型 / OCR+LLM / 检测器+LLM / VLM。
   **③「检测器 + 文本 LLM」是最被低估的形态**——要理解，但也要可控可审计。
7. **VLM 只用在真正需要「开放视觉理解」的地方**。
8. **行业里 AI 的角色要与责任匹配**：质检要人签字、诊断由医师确认、
   农技建议要结合法规——**这是责任问题，不是能力问题**。
9. **LLM-as-Judge 必须先校准再用**。
