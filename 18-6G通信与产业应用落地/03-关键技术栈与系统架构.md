# 03 · 关键技术栈与系统架构

> **核心问题：6G 的技术到底新在哪？「通感算智一体」是什么东西？AI 原生网络和现在的网络差在哪？**

---

## 0. 一张图看懂 6G 的技术栈

6G 的技术不是「一堆新名词」，而是**三条正交的主轴**在同一个系统里交汇：

```
┌──────────────────────────────────────────────────────────────────────┐
│  业务层  沉浸式通信 / 超可靠低时延 / 大规模连接 / 泛在连接 /          │
│           AI 与通信融合 / 通感一体化                                  │
├──────────────────────────────────────────────────────────────────────┤
│  功能层  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐   │
│           │ 通信 C │ │ 感知 S │ │ 算力 X │ │ 智能 I │ │ 安全 Q │   │
│           └────┬───┘ └────┬───┘ └────┬───┘ └────┬───┘ └────┬───┘   │
│                └──────────┴───── DOICT ─┴─────────┴─────────┘       │
├──────────────────────────────────────────────────────────────────────┤
│  接入层  AI 原生空口 / AI 原生 RAN(RAN Agent) / 通感一体基站 /         │
│           确定性无线接入 / 无蜂窝大规模 MIMO / RIS / 太赫兹与上中频   │
├──────────────────────────────────────────────────────────────────────┤
│  承载层  算力网络 / 边缘云 / 端边云智算一体 / 星地融合 / 卫星 NTN     │
├──────────────────────────────────────────────────────────────────────┤
│  基础层  频谱（U6G / 上中频 / 亚太赫兹）/ 器件（GaN / 射频前端） /    │
│           可持续性（能效、碳） / 后量子安全                           │
└──────────────────────────────────────────────────────────────────────┘
```

**「DOICT」** = Data-Of-Intelligence + Communication + Sensing + Computing，业内也写作
**通感算智一体 / 通感算智超融合**。紫金山实验室的 Pre-6G 试验网把它叫做 **DOICT 超融合**，
思科等厂商体系里对应 **CTI（Communication, Sensing, Computing, Intelligence）**。

**关键理解**：DOICT 不是「在基站旁边放一台服务器」，而是**四个域共享同一套资源池与编排**：
同一个频谱既能传数据也能探测；同一个算力池既跑协议栈也跑感知模型；同一个模型既能做流量预测也能做波束配置。
**这才是 6G 的架构性变化 —— 资源从「按功能切分」变成「按需编排」。**

## 1. 主轴一：AI 原生（AI Native）

### 1.1 从「网管带 AI」到「AI 是网的一部分」

通信网络的智能化有三代，边界很清楚：

| 阶段 | 形态 | 谁在做决策 | 代表 |
|---|---|---|---|
| 1.0 自动化 | 规则引擎 + 阈值告警 | 人定义的规则 | 传统网管、SON |
| 2.0 自智网络 | 机器学习做闭环 | 预训练模型 + 策略 | 3GPP ENI、华为 iMaster、爱立信 Intelligent Fabric |
| **3.0 AI 原生** | **模型即网元，网内嵌智能面** | **大模型 / 智能体（可被意图驱动）** | **RAN Agent、AISF、ACN** |

**3.0 阶段的核心变化有三个**：

1. **智能体进入控制回路**：从「告警给人」变成「智能体自己发现、自己决策、自己执行」。
2. **出现「AI 面」**：在传统控制面 / 用户面之外新增第三平面。
   华为的提法是 **AISF（AI Service Function）网元**，集成意图理解、体验感知、统一记忆。
3. **出现跨厂商的智能体接口**：否则每个厂商的智能体无法互相调用。
   华为联合 **TM Forum** 发布 **A2A-T（Agent-to-Agent-T）**，是电信业第一个智能体互操作接口规范。

### 1.2 落地证据：这些不是 PPT

### 1.3 AI 进空口：CIS-RAN 与无线基础模型

**CIS-RAN（Common Information Services over RAN）** 与 **MWFM（Multimodal Wireless Foundation Model）**
是学术界与产业界共同推进的路线，核心是把「无线数据」变成可预训练的数据资产。

三步走：

```
① 异构数据融合   →  把信道、CSI、位置、负载、天气、UE 行为统一成时空语料
② 大规模自监督预训练 →  得到「无线基础模型」
③ 快速适配下游任务   →  预测 / 调度 / 干扰管理 / 能耗优化 / 意图理解
                        ↓
              下一步：无线世界模型（world model，可仿真可反演）
```

**模型生命周期管理**（这是从 Demo 到生产的分水岭）：

```
性能监控 → 数据漂移检测 → 触发条件 → 数字孪生预验证 → 再训练 → 灰度上线
   ↑                                                              │
   └────────────────────── 效果回归监控 ←────────────────────────┘
```

> **工程结论**：**「数字孪生预验证」这一步是 6G 网络 AI 与普通 IT 系统 AI 的本质区别。**
> 通信网络的改动会物理地影响空口资源和覆盖，**不能像 Web 服务那样直接灰度到全网**。
> 任何声称「网管大模型已投产」的方案，都应该被问一句：**它在改配置前在哪里仿真过？**

### 1.4 AI for AI：网络侧要做的事，变成了 AI 侧的事

2026 年新出现的方向叫 **RAN for AI** —— 网络不只服务 AI，还为 AI 服务：

| 能力 | 说明 |
|---|---|
| **边缘推理卸载** | 把推理任务从终端/云端搬到网络边缘的合适位置 |
| **RAN 侧终止 PDU 会话** | 让 PDU 会话在无线接入网就终止，缩短路径 |
| **语义重要性感知调度** | 按「信息的重要性」而非「字节数」调度资源 |
| **通算协同 QoS** | 端到端延迟必须拆成**通信延迟 + 计算延迟**分别建模与保障 |
| **多模态无线基础模型** | 无线数据的统一表征 |

**「通算协同 QoS」是本节最实用的概念**，因为它给出了一条可落地的架构原则：

> **当一条链路同时跑通信和推理时，端到端 SLA 不等于无线 SLA。**
> 必须把延迟预算拆成「传输占多少、排队占多少、推理占多少」三段，
> 然后对每一段分别设预算与监控。**只看空口 KPI 的 SLA 设计，在 AI 原生网络里是不完整的。**

## 2. 主轴二：通感一体（ISAC）

### 2.1 感知是怎么「长」在通信上的

通信信号本来就是波。**波在遇到物体时会发生反射、多径、散射** —— 也就是说，
**任何能收发的无线节点，物理上都在被动地「看见」周围环境**。ISAC 做的是把这部分信息显式化、可用化。

| 能力 | 典型做法 | 用途 |
|---|---|---|
| **目标探测** | 目标反射信号与通信信号分离处理 | 低空无人机侦测、航道船舶 |
| **定位** | 多点接收 + 相位/时延测量 | 厘米级定位、室内定位、边坡形变测量 |
| **成像** | 宽带波形 + 成像算法 | 逆向合成孔径雷达（ISAR）式高分辨成像 |
| **环境感知** | 无线信道统计 + 温湿/振动/气体传感融合 | 桥梁形变、海洋牧场、水文 |
| **手势/活动** | 微多普勒特征分类 | 无摄像头的人体感知 |

**这一条解释了为什么 6G 的定位精度指标是厘米级、而 5G-A 通感一体也能做到亚米级**：
原理相同，差别在带宽、相位分辨率和阵列规模。

### 2.2 感知的三条变现路线

学界与产业界已经收敛出三种把「感知」变成生意的框架：

1. **Sensing-as-a-Service（感知即服务）** —— 感知能力打包成 API/切片，按次或按订阅计费。
   三星力推，牵头 3GPP ISAC 标准化。
2. **感知切片（Sensing Slice）** —— 在网络切片框架里新增感知资源维度，
   可以按「行业 + 空域 + 精度」组合售卖。
3. **感知 + 通信融合服务** —— 不单独卖感知，而是卖「通信 + 感知 + 定位」的融合体，
   比如低空监管方同时买「通信保障 + 空域态势 + 目标识别告警」。

阿联酋 e& 与哈利法大学 2026-07 在 IEEE 开放通信期刊发表的 ISAC 产业路线图，
评估了 **30+ 用例、8 个行业域**，结论是：**工业自动化、车联网、低空空域管理**是最强的早期商业机会。
这条判断和中国的实践（低空、港口、车联网三线并进）高度一致。

### 2.3 感知带来的新风险

**感知数据是敏感数据，而且比通信数据敏感得多。**

| 风险 | 说明 |
|---|---|
| **位置追踪** | 感知 + 定位可以还原人的行为轨迹，敏感度远超普通网络日志 |
| **生物识别** | 步态、毫米波生命体征属于生物识别信息，受《个人信息保护法》单独同意与 GDPR 特殊类别条款约束 |
| **场所监控** | 感知能力一旦可被第三方调用，等于在公共空间部署了隐形摄像头 |
| **数据权属** | 谁拥有感知产生的数据？基站、运营商、还是被感知的对象？ |
| **对抗攻击** | 感知信号可被干扰/欺骗（对抗样本式的物理攻击） |

> **工程结论**：**ISAC 的商业化速度最终会被合规而不是技术卡住。**
> 设计任何 ISAC 商业方案时，「感知数据的使用边界与授权链」必须与「感知精度指标」同等优先，
> 否则会出现技术验收通过、商务无法签约的局面。

## 3. 主轴三：无线与硬件的六个增量

### 3.1 上中频（Upper Mid-Band，6–8 GHz）

被称为「**6G 黄金频段**」—— 因为它同时兼顾覆盖与速率：

- 带宽够（连续 700 MHz 甚至更多）
- 传播特性比毫米波好得多（可支持更远距离和更高速移动）
- 是 **AI 原生网络、增强型 Massive MIMO、通感一体** 的共同载波

WRC-27 议程 1.7 的核心争议就在这里。**GSMA 要求全球协调 200–400 MHz 的 harmonized 频道**，
中国已先行批复 6425–7125 MHz 用于试验。

### 3.2 亚太赫兹 / 太赫兹（> 100 GHz）

- 频谱资源极大，是峰值速率的物理来源
- 代价：极高的路径损耗、强方向性、器件不成熟
- 中国已批复 6 GHz 试验频率，**用于验证太赫兹通信、Massive MIMO、智能超表面**
- 产业现状：3 nm 以下太赫兹前端模块进入**流片验证**；太赫兹单芯片成本较 2024 年降约 40%

> ⚠️ **不要把「太赫兹」当成 6G 的必经之路。**
> 3GPP 已明确 6G 空口在 **3 MHz – 400 MHz** 范围内设计，中频最大 100 MHz。
> **太赫兹是 6G 的一部分（热点容量场景），不是 6G 的定义。**
> 真正撑起 6G 主流体验的，是上中频 + 大规模 MIMO + AI 原生。

### 3.3 大规模 MIMO 与无蜂窝化

- **Massive MIMO**：仍是 5G-A 主力技术，6G 面向「无蜂窝大规模 MIMO」演进
  （南京 Pre-6G 试验网采用无蜂窝大规模 MIMO + 智能抗干扰）
- **无蜂窝化（cell-free）**：去掉「小区」这个概念，用户同时被多个接入点服务。
  这对**连续覆盖**（低空、海面）与**无切换中断**（高速移动 1000 km/h 目标）有本质意义。

### 3.4 智能超表面（RIS）

用可编程电磁单元被动地调整信道环境，**不发射信号就能改变传播路径**。

- 收益：补盲、扩展覆盖、降低对高增益功放/波束赋形的依赖
- 代价：控制面复杂度、被动链路的信道估计难题
- 商业价值最直接的场景是**室内与遮挡严重的场景**（厂区、楼宇、地下空间）

### 3.5 确定性无线接入

工业场景的核心诉求不是「平均时延低」，而是**「有上界的时延」**。

```
概率分布视角：
  5G 说的是「平均 1 ms」
  确定性说的是「99.9999% 的包在 X ms 内到，且抖动有界」
```

南京 Pre-6G 试验网给出的口径是**空口时延低至几十微秒、可靠性 99.9999%**，
工业无线控制场景验证「毫秒级确定性通信」，用于包装印刷、自动装配产线摆脱有线束缚。

### 3.6 空天地海一体化

- **NTN（Non-Terrestrial Network）**：卫星作为地面网的补充，支撑 UC（泛在连接）场景
- **星地融合**：2026 年 IMT-2030 推进组新设**星地融合工作组**
- 中国星座资源：千帆星座超 1.5 万颗、GW 星座约 1.3 万颗（在轨规划）
- 难点：切换机制、时延不对称、频谱协调（这正是 WRC-27 议程 1.13/1.12/1.14 要解决的）

## 4. 能效：6G 最硬的约束

6G 不是「无限带宽」，它被**能效与碳排**死死卡住。

| 数据 | 口径 |
|---|---|
| **0.1 纳焦/比特** | 头部企业 6G 原型基站的能效，较 5G 原型**下降 72%** |
| **流量增长 8.5 倍** | 2025–2030 全球数据流量预测增长 |
| **+4–6 倍** | 次太赫兹部署可能导致 **RAN 能耗**的增幅（悲观估计） |

**为什么这是个真问题**：如果 2030 年流量增长 8.5 倍，而单 bit 能效只改善 2 倍，
那么**总能耗会涨 4 倍以上**。运营商在电价、碳排指标与资本开支三重约束下，不可能接受这个账单。

于是 **能效不再是「环保指标」，而是「成本指标」**：

- **智能关断与协作休眠**：没有用户的扇区进入深度休眠，有请求时唤醒
- **能效优化进入 RAN Agent 的闭环**：华为披露的 5.5% 全网节能增益就是这个逻辑
- **M.2160 把「可持续性」列为跨场景设计原则**，并把能效写进 15 项能力之一

> **工程结论**：任何 6G 方案评估，**必须问「每 bit 能耗」和「每用户每小时 CAPEX」两个数**。
> 只讲峰值速率的方案在运营商的资本开支评审里过不了关 —— 因为它把成本转移给了能耗，
> 而运营商的能耗是要进成本表的。

## 5. 架构总览：一张从终端到卫星的图

```
┌───────────────┐   ┌───────────────┐   ┌───────────────┐
│  终端域        │   │  接入域        │   │  边缘域        │

│  · 机器人/无人机 │   │  · ISAC 基站   │   │  · 感知融合    │
│  · 工业网关     │   │  · RIS/透镜天线│   │  · 推理卸载    │
│  · 卫星载荷     │   │  · 星地融合    │   │  · 数字孪生    │
└───────┬───────┘   └───────┬───────┘   └───────┬───────┘
        │                   │                   │
        └───────────────────┼───────────────────┘
                            ▼
                  ┌───────────────────────┐
                  │   AI 原生核心网         │
                  │  · AISF（AI 面）        │
                  │  · 意图驱动 / ACN 智能体│
                  │  · 通算融合资源池       │

                  └───────────┬───────────┘

                  ┌───────────────────────┐
                  │   云 / 智算 / 数据      │

```

三个必须点名的架构要素：

1. **AI 面（AISF / ACN）** —— 控制面与用户面之外的新平面，承载意图理解、体验感知、统一记忆。
2. **通算融合资源池** —— 算力与通信资源统一编排，是「以算补通」「以通换算」的物理基础。
   中国移动研究院等 8 家单位发布的《6G 通算融合赋能具身智能白皮书》即持此观点。
3. **感知数据治理面** —— 感知产生的数据需要独立的权限、留存、审计链路，
   这是 ISAC 商业化的合规前提（见 §2.3）。
