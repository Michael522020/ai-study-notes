# 18 · 6G 通信与产业应用落地

> **从「2030 年才有的标准」到「今天就能买到的能力」：6G 的技术、产业地图，以及一份能拿去谈事的落地清单。**

前七条主线讲的是 **AI 本身**（模型、检索、Agent、部署）。这一条讲的是**承载 AI 与一切数字化业务的下一张网**。

**为什么把它放进 AI 研究笔记？** 因为 6G 已经不是单纯的通信技术升级 ——
它的六大场景里有两个（**AI 与通信融合**、**通感一体化**）本质上就是 AI 问题，
而它的产业落地清单（低空、工业、机器人、港口、应急），
逐条对应着检测模型、边缘部署、RAG、Agent 工程这些已经在本仓库里写过的东西。

**这条主线的写法有两条硬规矩**：

1. **所有数字标口径。** 6G 领域是指标通胀的重灾区 —— 「1 Tbps 峰值」「0.1 ms 时延」「探测概率 97.9%」
   这类数字离开了测量条件就没有意义。本目录每个数字都尽量写清「谁公布、在什么条件下、能不能横向比」。
2. **区分「6G 的事」和「现在该做的事」。** 商业现实是：**2030 年才有 6G，
   但 6G 要解决的问题今天就在发生**（低空监管、工业柔性产线、机器人联网、灾害应急）。
   **本目录每个行业都给出「等 6G / 不等 6G」的明确判断。**

## 🧭 八份笔记的共同结论

1. **6G 不是更快的 5G，是把通信、感知、计算、智能、安全合成一张网。**
   6G 空口在 2026-06 已明确延续 CP-OFDM 与 5G 帧结构 —— **差异化不在波形，在网络的功能构成。**
2. **ITU 的 15 项关键能力里，有 6 项是 5G 完全没有对应物的：**
   覆盖、厘米级定位、感知能力、AI 能力、可持续性、互操作。**这 6 项才是 6G 的定义。**
3. **所有指标必须带口径，否则不能用于验收。**
   「探测概率 97.9%」若不附虚警率、目标 RCS、空域高度、分母，**这句话在工程上没有任何意义**。
4. **2026 年能买到的「6G 能力」几乎全部是 5G-A 与 Pre-6G 形态。**
   把 2030 年的宣传语当采购依据，是这个行业最常见的误判。
5. **ISAC 是最先跑通商业闭环的场景**（低空、港口、水域），因为它把
   「雷达 + 光电 + 通信」三套系统压成一套，**省的是建设与运维成本，不是带宽**。
6. **感知系统的验收指标必须是「探测概率 + 虚警率」的组合。**
   虚警高会导致告警疲劳，一线关掉告警 = 系统失效。
7. **感知数据的合规风险大于技术风险。**
   卖「感知能力」可行，卖「感知数据」在法律上是高危的 —— **这个区别在很多方案里被刻意模糊。**
8. **绝大多数「6G 项目」应该判为「不等」。**
   真正的判据是三条筛子：通信约束是否硬、5G-A 能不能顶、6G 的增量能力是否不可替代。
9. **AI 原生网络已经落地了**，形态是 RAN Agent + AN Level 认证 + 订阅制软件（爱立信 2026-06 商用订阅）。
   **诚实的自动化率（15% 自动闭环）比夸张的（95%）更可信。**
10. **能效是成本问题，不是环保问题。** 流量 2025–2030 预计涨 8.5 倍，
    单 bit 能效若只改善 2 倍，总能耗就涨 4 倍 —— **运营商的账单算得清这笔账。**

## ⚠️ 关于本目录数据的性质

- **本目录作者未参与任何 6G 试验网建设、标准制定或厂商设备评测。**
- 所有标准、时间线、政策数据转述自 **ITU / 3GPP / 工信部 / IMT-2030 推进组** 的公开发布。
- 所有性能数字（探测概率、时延、覆盖率、能效等）**均为各厂商或运营方自行披露的现网/实验室数据**，
  多数未提供统一的第三方复测口径，**引用时必须标注披露方，不得跨厂商直接比较**。
- 市场规模与资本开支数据来自 **中国信通院、赛迪顾问、Dell'Oro、GSMA、中商产业研究院** 等公开报告，
  **各机构统计边界不同（网络市场 / 核心产业 / 带动产出可差 7 倍）**，横向对比前必须统一口径。
- 行业成熟度打星、风险排序、买卖方判断为**作者观点**，不构成投资、采购或合规意见。
- 本目录所有第三方标准、白皮书、报告与论文**均归属各自作者/机构**，
  **本仓库只收录研究笔记，不收录任何第三方原文与源码。**
