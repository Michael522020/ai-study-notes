# 分割、实例与全景

> **核心问题**：检测输出的是框，但很多任务需要「像素级」的答案。从 FCN 到 SAM，这条线怎么走的？

---

## 1. 分割任务的三个层次

| 任务 | 输出 | 例子 |
|---|---|---|
| **语义分割** | 每个像素一个类别（不区分实例） | 道路/天空/建筑 |
| **实例分割** | 每个像素一个 (实例 ID, 类别) | 每辆车各自的 mask |
| **全景分割** | 语义 + 实例统一（stuff + things） | 自动驾驶全场景理解 |

**核心差异**：语义分割的「天空」像素可以来自图像各处；实例分割要求同一实例的像素是连通的。

## 2. 语义分割：FCN 及后继

### 2.1 FCN（2015）

**论文**：*Fully Convolutional Networks for Semantic Segmentation*, CVPR 2015

**核心思想**：把分类网络改成**全卷积**，去掉全连接层，输出与输入同分辨率（或上采样后同分辨率）的类别图。

```
骨干（去掉 FC）→ 特征图 (C×H/32×W/32)
    ↓
1×1 Conv → 类别分数图 (num_classes × H/32 × W/32)
    ↓
上采样 ×32 → (num_classes × H × W)
    ↓
逐像素 softmax + 交叉熵
```

**两个关键技术**：

#### 技术 1：Skip Connection（跳跃连接）

```
骨干浅层 (H/2 × W/2, 高分辨率) ─────────────┐
                                            ↓ concat
骨干深层 (H/32 × W/32, 语义强) → 上采样 ────┘
```

**FCN-8s** 用 2× 和 4× 的浅层特征做更细的 skip。

#### 技术 2：上采样方式

| 方式 | 说明 |
|---|---|
| **反卷积 (Deconv)** | 可学习，有棋盘伪影 |
| **双线性插值** | 简单有效 |
| **PSP / PPM** | 多尺度池化 |
| **转置卷积 + BN** | DeepLabv3 之前的常用 |

### 2.2 PSPNet（2016）

**论文**：*PSPNet: Pyramid Scene Parsing Network*, CVPR 2016

**金字塔池化模块（PPM）**：

```
输入特征 (C×H×W)
    ↓ 并行:
    ├─ AdaptiveAvgPool 1×1 → Conv → 膨胀 (H×W)
    ├─ AdaptiveAvgPool 2×2 → Conv → 膨胀 (H×W)
    ├─ AdaptiveAvgPool 3×3 → Conv → 膨胀 (H×W)
    └─ AdaptiveAvgPool 6×6 → Conv → 膨胀 (H×W)
    ↓ Concat (4C)
    ↓ Conv 3×3
```

**作用**：用全局池化获得**全局上下文信息**（原图哪部分是什么），弥补卷积的局部性。

### 2.3 DeepLab 系列

| 版本 | 年份 | 关键改进 |
|---|---|---|
| **DeepLab v1** | 2014 | 空洞卷积 + CRF |
| **DeepLab v2** | 2016 | **ASPP**（空洞空间金字塔池化） |
| **DeepLab v3** | 2017 | **网格化空洞卷积**（解决空洞卷积的 gridding artifact）+ BN |
| **DeepLab v3+** | 2018 | 编码器用 ResNet/Deformable Conv，多尺度输出 + 解码器 |

**空洞卷积（Dilated / Atrous Convolution）**：

$$
\text{out}[i] = \sum_{k=1}^{K} w[k] \cdot \text{in}[i + k \cdot d]
$$

**作用**：在**不增加参数量**的情况下扩大感受野。

**问题**：dilation rate 太大时，相邻采样点距离太远，出现 **gridding artifact**（网格化伪影）。

**DeepLab v3 的网格化卷积**：把 dilation rate 组合成 $(r, r^2, r^3)$，让采样点在多个尺度上均匀分布。

### 2.4 SegFormer（2021）

**论文**：*SegFormer: Simple and Efficient Design for Semantic Segmentation with Transformers*, NeurIPS 2021

**两个核心设计**：

#### 设计 1：Mix Transformer 编码器

```
Hierarchical Transformer（分层 ViT）
    ↓ 每层输出不同尺度的特征（步长 4/8/16/32）
```

与普通 ViT 的区别：**分层 + 有重叠 patch embedding** → 既保留 ViT 的全局注意力，又有卷积网络的层级结构。

#### 设计 2：轻量 All-MLP 解码器

```
多尺度特征 → 每个都过 MLP 统一到同一维度 → Concat → MLP → 上采样
```

**去掉位置编码**（用卷积代替），参数量比 DeepLabv3+ 少 8 倍，训练快 2 倍。

**性能**：ADE20K 47.6 mIoU，与 DeepLabv3+ 相当但快 2 倍、参数少 8 倍。

### 2.5 现代语义分割的现状

| 方法 | 骨干 | 特点 |
|---|---|---|
| **DeepLabv3+** | ResNet/ConvNeXt | 经典稳定 |
| **SegFormer** | MiT | 轻量高效 |
| **Mask2Former** | 多种 | **统一框架**（见 §4） |
| **OneFormer** | Swin/ConvNeXt | 统一所有分割任务 |
| **SegNeXt** | MSCAN | MSCAN 骨干 |
| **HRNet** | — | 保持高分辨率 |
| **DDRNet** | — | 实时（城市街景） |
| **PIDNet** | 2023 | 三分支（proportional/...），实时高精度 |

**实时语义分割**（<10 FPS 要求）：
- **DDRNet**（ICCV 2021）：**分辨率分支**（高分辨率细节 + 低分辨率语义）
- **PIDNet**（CVPR 2023）：三分支
- **BiSeNet v2**：**分支式**（上下文分支 + 空间分支），用 **Gather-and-Affine** 代替交叉拼接

## 3. 实例分割

### 3.1 Mask R-CNN（2017）

见 [`02-两阶段检测器.md`](./02-两阶段检测器.md) §6。

**核心**：在 Faster R-CNN 上加一个 mask 分支，用 RoIAlign 提取的特征做 mask 预测。

### 3.2 Mask R-CNN 的问题

| 问题 | 说明 |
|---|---|
| **Mask 分辨率低** | 28×28 的 mask，要放大到原图 |
| **类别耦合** | 每个类别一个 mask 通道，类别多时参数量爆炸 |
| **依赖框** | mask 质量受框质量限制 |

### 3.3 PointRend（2020）

**论文**：*PointRend: Image Segmentation as Rendering*, NeurIPS 2020

**思想**：把分割当成「渲染」—— 只在**最有价值的位置**精细计算。

```
粗分割 (低分辨率, 如 28×28) → 上采样
    ↓
选择「不确定」的点（分类熵最高 / 靠近边界）
    ↓
在这些点对应的位置，用双线性插值提取精细特征
    ↓
Point Head 预测这些点的精细 mask
    ↓
拼接回粗 mask
```

**收益**：用 28×28 的粗 mask 达到接近全分辨率的精度。

### 3.4 Mask2Former（2021/2022）

**论文**：*Mask2Former: Masked-attention Mask Transformer for Universal Image Segmentation*, CVPR 2022
**仓库**：`facebookresearch/Mask2Former`

**核心：Masked Attention**

标准注意力：
$$
\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V
$$

**问题**：对分割来说，每个 query 应该只关注**它负责的那个区域**，而不是全图。

**Masked Attention**：
$$
\text{Masked-Attn}(Q, K, V) = \text{softmax}\left(\frac{Q + \mathcal{M}_{q}K^T}{\sqrt{d}}\right)V
$$

其中 $\mathcal{M}_q$ 是 query $q$ 的 **mask 矩阵**（由前一轮的 mask 预测生成）。

**效果**：每个 query 只在「自己负责的区域」内做注意力 → 收敛快、精度高。

**统一框架**：同一套架构 + 不同的 mask 预测头，就能做：
- 语义分割（一个 query / 一个类别）
- 实例分割（一个 query / 一个实例）
- 全景分割（额外加一个「stuff」query 处理背景类）

**性能**：
| 数据集 | 指标 | Mask2Former |
|---|---|---|
| COCO | box AP | 47.1 |
| COCO | mask AP | 44.9 |
| ADE20K | mIoU | 56.1 |
| Cityscapes | mIoU | 74.1 |

## 4. Segment Anything（SAM, 2023）

**论文**：*Segment Anything*, arXiv:2304.02643
**仓库**：`facebookresearch/segment-anything`

### 4.1 范式转变

**之前的分割模型**：针对固定类别集训练（Cityscapes 的 19 类、ADE20K 的 150 类）。

**SAM 的想法**：分割应该是**可提示的（promptable）**任务 —— 给一个点/框/掩码提示，模型分割出对应的区域。

**类比**：把 SAM 当成「视觉领域的 Segment Anything Model」—— 一个通用的、可提示的分割引擎。

### 4.2 三大组件

#### 组件 1：SA-1B 数据集

**11 million images, 11 billion masks** —— 史上最大的分割数据集。

**构建方法（自动化标注 pipeline）**：
```
1. 网格采样点 → 提示 SAM（初始是手动标注的模型）
2. 得到初始 mask
3. 用 overlap 筛选：保留「完全包含在框内」和「边界清晰」的 mask
4. 用自动 mask 生成器（训练好的模型）生成更多
5. 人工复核 1.7% 的数据
```

**规模对比**：
| 数据集 | 图像数 | mask 数 |
|---|---|---|
| COCO | 328K | 2.6M |
| **SA-1B** | **11M** | **11B** |
| Open Images | 9M | — |

#### 组件 2：SAM 模型

```
                ┌──────────────────────────────┐
图像 →          │  Image Encoder (ViT-H)       │ → 图像 embedding
                │  一次前向，缓存               │    (64×64×1024)
                └──────────────────────────────┘
                                ↓
        ┌───────────────────────┼───────────────────────┐
        ↓                       ↓                       ↓
   [点提示]                [框提示]              [掩码提示]
        └───────────────────────┼───────────────────────┘
                                ↓
                ┌──────────────────────────────┐
                │  Mask Decoder (轻量)          │
                │  Transformer decoder          │ → 3 个 mask
                │  + prompt token               │   + IoU 预测
                └──────────────────────────────┘
```

**关键架构决策**：

| 决策 | 理由 |
|---|---|
| **编码器一次性，缓存 embedding** | 多次提示只需跑一次编码器 → 交互式分割可行 |
| **编码器重、decoder 轻** | 编码器 636M 参数，decoder 16M |
| **输出 3 个 mask（多粒度）** | 整物体 / 部分 / 子部分，让用户选择 |
| **输出 IoU 预测** | 给出 mask 的质量估计，可用于排序筛选 |

#### 组件 3：提示机制

| 提示类型 | 说明 |
|---|---|
| **点提示** | 正点（在这里）/ 负点（不在这里） |
| **框提示** | 一个 bbox |
| **掩码提示** | 上一轮输出的 mask（用于迭代修正） |
| **组合** | 点 + 框 |

### 4.3 SAM 的性能

| 模型 | ViT-B | ViT-L | ViT-H |
|---|---|---|---|
| 参数量 | 91M | 308M | 636M |
| 速度 (A100) | 103 FPS | — | — |

在 23 个数据集上达到 SOTA 或接近 SOTA。

**SA-1B 训练的 SAM-H 的分割性能超过所有之前的分割模型。**

### 4.4 SAM 2（2024）

**论文**：*SAM 2: Segment Anything in Images and Videos*, arXiv:2408.00714

**从图像到视频**：

| 维度 | SAM 1 | SAM 2 |
|---|---|---|
| 输入 | 图像 | 图像序列（视频） |
| 记忆机制 | 无 | **流式记忆机制**（Memory Attention） |
| 时序一致性 | 无 | 掩码在帧间传播 |
| 数据 | SA-1B (11M 图像) | **SA-V**（视频，含 60.9K 视频、约 6M 帧） |
| 模型规模 | ViT-H | ViT-H+ |

**记忆机制**：
```
当前帧特征 + 之前帧的「记忆特征 + 记忆位置编码」
       ↓
Memory Attention（把记忆当作额外的 K/V）
       ↓
当前帧的 mask
```

**效果**：视频分割的质量和效率都大幅提升，且能处理**遮挡后重新出现**的目标（靠记忆）。

## 5. SAM 生态

| 项目 | 说明 |
|---|---|
| **FastSAM** | 把 SAM 的编码器换成 YOLOv8 骨干，速度快 10~20× |
| **MobileSAM** | TinyViT 编码器，移动端友好 |
| **EfficientSAM** | 轻量 ViT + 蒸馏 |
| **EdgeSAM** | 面向边缘设备 |
| **HQ-SAM** | 高质量分割（细边界） |
| **Grounded-SAM** | Grounding DINO + SAM → 文本提示分割 |
| **SAM-HQ / HQ-SAM** | 提升小物体和细边界 |
| **MedSAM / SAM-Med2D / SegVol** | 医学影像 |
| **Segment Anything 3** | — |

### 5.1 Grounded-SAM 的组合范式

```
文本提示 "yellow school bus"
      ↓
[Grounding DINO] → 框
      ↓
[SAM] 框作为提示 → 精细 mask
```

**这是零样本分割的标准流程**，在 Grounded-SAM 之前，你需要为每个类别训练一个分割模型。

## 6. 分割模型的选型

| 需求 | 推荐 |
|---|---|
| **固定类别语义分割（离线）** | SegFormer / DeepLabv3+ / Mask2Former |
| **实时语义分割（<20 FPS）** | BiSeNet v2 / PIDNet / DDRNet |
| **固定类别实例分割** | Mask2Former / Mask R-CNN（成熟稳定） |
| **零样本 / 任意类别分割** | **SAM / SAM 2**（+ Grounding DINO 做文本提示） |
| **视频分割** | **SAM 2** / SAM2Long / XMem |
| **视频实例分割** | VIS / SeqFormer / TEViT |
| **交互式编辑（标注辅助）** | **SAM**（点/框提示，人工修正） |
| **医学影像** | MedSAM / SAM-Med3D |

---

## 7. 工程结论

1. **SAM 是标注效率的利器**。用它做预标注（pseudo-label）再人工修正，通常能把标注成本降到 1/5~1/10。**这是最实用的 SAM 用法。**
2. **Grounded-SAM（文本 → 框 → mask）打开了零样本分割的大门**，适用于「类别未知但有文本描述」的场景。
3. **语义分割和实例分割的选型逻辑完全不同**：语义分割要「全局一致性」，实例分割要「实例区分度」。
4. **Mask2Former 的统一框架值得学习** —— 一个架构做三个任务，说明任务差异主要在「mask 预测头」和「query 语义」。
5. **视频用 SAM 2，图像用 SAM 1 或 SAM 2**。SAM 2 的记忆机制对视频是必需的。
6. **实时分割是独立的赛道**（DDRNet / PIDNet / BiSeNet），不要用分割大模型硬扛。
