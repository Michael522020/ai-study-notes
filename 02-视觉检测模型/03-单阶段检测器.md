# 单阶段检测器

> **核心问题**：把「先提 region 再分类」压成「一次前向」，精度掉在哪、怎么补回来？

---

## 1. 单阶段范式的本质

```
        ┌─────────────────────────────┐
图像 →  │  Backbone + FPN              │ → 特征图
        └─────────────────────────────┘
                          ↓
        每个特征位置直接预测框和类别（dense prediction）
                          ↓
                    NMS / 端到端
```

**与两阶段的本质区别**：**没有「proposal → 逐框精修」这一步**。所有位置的预测是**并行**的，靠「样本分配」决定哪个位置负责哪个目标。

**带来两个根本问题**：
1. **正负样本极不平衡**：一张图 8400 个位置，GT 可能只有 5 个
2. **缺少「精修」机会**：没有第二次看目标的机会，定位精度受限

单阶段流派的全部工作，基本就是在解这两个问题。

## 2. SSD（2016）

**论文**：*SSD: Single Shot MultiBox Detector*, ECCV 2016
**作者**：Liu, Anguelov, Erhan et al. (Google)

### 2.1 结构

```
VGG-16 Backbone
    ↓
多尺度特征图: conv3_3 (38×38), conv4_3 (19×19), conv7 (10×10), +额外卷积层
    ↓
每个特征图位置预测:
   - 类别分数 (21 类含背景)
   - 默认框 (default box) 的偏移量
    ↓
所有尺度的预测汇总 → Softmax → NMS
```

### 2.2 关键设计

| 设计 | 说明 |
|---|---|
| **Default Box（锚框）** | 每个位置预设多个不同宽高比的框 |
| **多尺度预测** | 小目标在高层用大 default box，大目标在低层用小 default box（因为低层分辨率高） |
| **Hard Negative Mining** | 负样本按 loss 排序，只保留 loss 最高的 3:1 比例 |

### 2.3 Hard Negative Mining

**问题**：背景负样本远多于正样本，直接学会让模型全预测背景。

**解法**：在负样本中选 loss 最高的若干个（3 倍正样本数），其余忽略。

**这是 OHEM（Online Hard Example Mining）的简化版**，在深度学习时代被广泛使用。

### 2.4 性能

- VOC 2007 test：74.3 mAP（512×512 输入），73.2 FPS（Titan GPU）
- COCO：mAP 远低于两阶段

## 3. RetinaNet（2017）— 里程碑

**论文**：*Focal Loss for Dense Object Detection*, ICCV 2017
**作者**：Lin, Goyal, Girshick, He, Dollár

### 3.1 解决的问题

**这是单阶段流派最重要的一篇论文。** 它回答了「为什么单阶段比两阶段精度低」这个核心问题：

> **不是架构不好，是正负样本不平衡导致的。**

**证据**：在**相同特征提取器**下：
- Faster R-CNN（两阶段）：单阶段 head 直接做检测 → 精度暴跌
- RetinaNet（用 Focal Loss 的单阶段）→ 精度追平 Faster R-CNN

### 3.2 Focal Loss 推导

**CE Loss**：
$$
\text{CE}(p_t) = -\log(p_t)
$$

**问题**：当 $p_t \ll 0.01$（易分负样本）时，$\text{CE} \approx p_t$，但**这些样本的数量是压倒性的**。

举例：1000 个正样本 + 100000 个负样本，即使每个负样本 loss 只有 0.01，总 loss = 1000，而正样本可能每个 loss 2.0，总共 2000 —— 负样本贡献了 1/3 的梯度。而实际上负样本「很容易分」，对模型提升几乎无用。

**Focal Loss**：
$$
\text{FL}(p_t) = -(1-p_t)^\gamma \log(p_t)
$$

**直觉**：给「已经分对的样本」降低权重（$(1-p_t)^\gamma$），给「分错的样本」保持高权重。

- $\gamma = 0$：退化为 CE
- $\gamma = 2$：标准配置
- 易分样本 $p_t = 0.99$：权重 $(0.01)^2 = 0.0001$ → **几乎不贡献梯度**
- 难分样本 $p_t = 0.3$：权重 $(0.7)^2 = 0.49$ → 保持

**加上调制系数**：
$$
\mathcal{L} = -\frac{1}{N}\sum_i \alpha_i (1-p_{t,i})^\gamma \log(p_{t,i}), \quad \alpha_t = 0.25, \alpha_{1-t} = 0.75
$$

### 3.3 RetinaNet 结构

```
        ┌──────────────────────────────┐
图像 →  │  ResNet-50 Backbone           │
        └──────────────────────────────┘
                    ↓
        ┌──────────────────────────────┐
        │  FPN Neck (P3-P7, 5 levels)   │  ← 借用了 Faster R-CNN 的 FPN
        └──────────────────────────────┘
                    ↓
        ┌──────────────────────────────┐
        │  共享的 4×4 conv + 3×3 conv    │  ← 所有 FPN 层共享权重！
        └──────────────────────────────┘
                    ↓
              ┌─────┴─────┐
              ↓           ↓
         分类子网      回归子网
         (C classes   (4 × 9 = 36
          + 背景)       anchors per loc)
```

**两个关键设计**：

| 设计 | 说明 |
|---|---|
| **FPN 借鉴** | RetinaNet 直接用了 Faster R-CNN 的 FPN neck，说明 FPN 是通用红利 |
| **子网权重共享** | 所有 FPN 层的分类/回归子网共享参数 → 减少过拟合，加速训练 |

### 3.4 性能

COCO val（640，5× 训练 schedule）：

| 模型 | AP | AP50 | AP75 | AP_s | AP_m | AP_l |
|---|---|---|---|---|---|---|
| Faster R-CNN | 37.9 | 58.5 | 42.8 | 20.2 | 41.1 | 54.1 |
| **RetinaNet** | **36.5** | 56.8 | 42.1 | 19.8 | 40.9 | 53.6 |
| RetinaNet (Focal Loss 消融) | 31.9 | — | — | — | — | — |

**关键观察**：最后一行是**用普通 CE 训练的 RetinaNet**，掉了 4.6 AP —— 这就是 Focal Loss 的贡献。

### 3.5 意义

RetinaNet 确立了单阶段可以达到两阶段精度的认知，从此单阶段成为**工业部署的主流**（YOLO 系正是沿着这条路走的）。

## 4. FCOS（2019）— Anchor-free 的奠基

**论文**：*FCOS: Fully Convolutional One-Stage Object Detection*, ICCV 2019
**作者**：Tian, Kong, Shen, Jiang

### 4.1 核心：逐像素预测

不用 anchor，每个位置 $(i,j)$ 直接预测到 GT 四条边的距离：

$$
\begin{aligned}
l &= i - x_{\min}, \quad t &= j - y_{\min} \\
r &= x_{\max} - i, \quad b &= y_{\max} - j
\end{aligned}
$$

### 4.2 三个关键设计

#### 设计 1：Centerness 中心度

**问题**：每个位置都预测框，那么「一个目标内部的所有位置」都会预测出相似的框 → 大量重复框。

**解法**：预测一个「该位置有多接近目标中心」的打分：

$$
\text{centerness} = \left(\frac{\min(l,r)}{\max(l,r)} \cdot \frac{\min(t,b)}{\max(t,b)}\right)^{\beta}
$$

- 目标中心：centerness ≈ 1
- 目标边缘：centerness 小
- 远离目标：centerness → 0

**centerness 在推理时乘到分类得分上** → 中心位置被保留，边缘位置被抑制。

#### 设计 2：FPN 上的层级分配

```
P3 (stride 8):  负责 小目标  (尺寸 < 8×8 的归一化区域)
P4 (stride 16): 中目标
P5 (stride 32): 大目标
P6, P7:        更大目标（用 S2D conv 生成）
```

**分配规则**：GT 的中心落在哪一层，就由哪一层负责（每层中心区域 $\pm$ 半径范围内）。

#### 设计 3：回归目标归一化

不同 FPN 层的 stride 不同，直接预测像素距离会导致尺度不一致。FCOS 用 stride 归一化：

$$
\frac{l}{s}, \frac{t}{s}, \frac{r}{s}, \frac{b}{s}
$$

其中 $s$ 是该层 stride。

### 4.4 性能

COCO val：**37.3 AP**（单尺度，无 TTA），比 RetinaNet 快且精度相当。

**FCOS 的历史意义**：
1. 证明了 anchor-free 的可行性 → 后续 ATSS、GFL、TOOD、FCOSv2、YOLOv8 全是它的继承者
2. 提出了 centerness → 后来 YOLOv8 用的是简化版（直接把中心距离编进 DFL 的目标）

## 5. ATSS（2020）— 动态样本分配

**论文**：*Bridging the Gap Between Anchor-based and Anchor-free Detection via Adaptive Training Sample Selection*, CVPR 2020

**详细算法** → [`04-无锚框与样本分配.md`](./04-无锚框与样本分配.md)

**核心思想**：**正样本的选择由预测质量决定，而不是由固定阈值决定**。

**结果**：把 ATSS 移植到 RetinaNet 上，AP 从 37.4 提升到 39.6（+2.2），且**只用 1× 训练 schedule**。

## 6. GFL（2020）— 分布回归

**论文**：*Generalized Focal Loss: Learning Qualified and Distributed Bounding Boxes*, NeurIPS 2020
**作者**：Li, Zhang, Han, Jiang et al. (华为诺亚)

### 6.1 核心：把回归变成分布学习

**问题**：标准的边界框回归用 L1/L2 直接回归 4 个数，是「点估计」，没有建模不确定性。

**GFL 的思想**：预测一个**离散分布**，表示「边界位置的不确定性」。

### 6.2 质量 Focal Loss（Quality Focal Loss）

**推广 Focal Loss**：从「二分类（前景/背景）」扩展到「连续的质量标签」。

$$
\text{QFL} = -\sum_{y \in \{0,1\}} y \cdot \text{CE}(y, \hat{y}) \cdot |y - \hat{y}|^\gamma
$$

其中 $\hat{y} \in [0,1]$ 是**预测的 IoU 质量**（分类分支输出 1 个额外通道预测 IoU）。

**直觉**：Focal Loss 对「分错的样本」加权；QFL 进一步对「预测质量与真实质量差距大」的样本加权，且**软化了正负的二值划分**。

### 6.3 分布 Focal Loss（DFL）

**这是 YOLOv8/v11 用的那个 DFL。**

**边界分布**：把一条边界离散成 $n$ 个 bin，预测每个 bin 的概率：

$$
\text{target}(k) =
\begin{cases}
k - d & k = \lfloor d \rfloor \\
d - k & k = \lceil d \rceil \\
0 & \text{其他}
\end{cases}
$$

$$
\mathcal{L}_{\text{DFL}} = \text{CE}(\text{softmax}(\hat{l}), \text{target})
$$

**推理时取期望**：
$$
\hat{d} = \sum_{k=0}^{n-1} k \cdot \text{softmax}(\hat{l})_k
$$

**为什么有效**：
1. 建模了定位的**不确定性**（分布的形状有意义）
2. 相邻 bin 有监督重叠 → **位置间的一致性**（相邻网格点预测的框应该连续）
3. 相比 L1，梯度更平滑，收敛更好

### 6.4 GFLv1 vs GFLv2

| 版本 | 改进 |
|---|---|
| **GFLv1** | 引入 QFL + DFL，替换掉 IoU Loss |
| **GFLv2** | 额外把**分类分支的质量估计和定位分支的分布**用 **Distribution Focal Loss** 统一度量（IoU = 分布 × 分布的期望），进一步提升 ~1 AP |

### 6.5 性能

COCO val：**45.0 AP**（ResNet-101，2× schedule），当时 SOTA。

## 7. VarifocalNet（2021）

**论文**：*VarifocalNet: An IoU-aware Dense Object Detector*, CVPR 2021

### 7.1 核心：star-shaped box

**问题**：anchor-free 的框回归用「到四条边的距离」表示（FCOS 风格），但这不保证框的形状合理。

**VarifocalNet 的表示**：把框编码为「中心到角点的向量」（8 维）：

$$
\text{box} = (x, y, \text{top-left}, \text{top-right}, \text{bottom-right}, \text{bottom-left})
$$

即**中心的相对偏移 + 四个角的相对位置**。这被称为 **star-shaped box**（框是从中心向四角发散的星形）。

**好处**：
1. **几何一致性**：预测的框天然是从中心发散的，避免「退化框」（宽度为 0 之类）
2. **尺度无关**：归一化后与小目标的兼容性更好

### 7.2 Varifocal Loss

QFL 的改进版，用 **IoU-aware 分类**代替「分类 + 质量」两路输出：

$$
\text{VFL}(p) = -q \log(p) - \alpha \cdot q' \log(1-p)
$$

其中：
- $q$ 是「该位置与 GT 的 IoU」（soft label，0~1）
- $q'$ 是「正负二值 target」
- 当 $q = q'$（位置在 GT 内）时，退化为标准 CE
- 当 $q > q'$（位置在 GT 内但 IoU 低）时，**惩罚更重** → 强制模型学准

**推理**：分类得分直接就是 IoU 感知的质量分，可用于 NMS 排序和阈值过滤。

### 7.3 性能

COCO val：**46.7 AP**（ResNet-101，3× schedule），当时单阶段 SOTA。

## 8. TOOD（2021）

**论文**：*TOOD: Task-aligned One-stage Object Detection*, ICCV 2021

### 8.1 问题

FCOS 系模型的分类分支和回归分支各自独立训练，但**两者的目标不一致**：
- 分类希望「这个位置是目标中心」
- 回归希望「这个位置的框最准」
- 两者对「什么是好位置」的判断标准不同 → 梯度冲突

### 8.2 Task-aligned 学习

**两个机制**：

| 机制 | 说明 |
|---|---|
| **Task-Aligned 学习** | 分类和回归的监督样本**由同一个分配器选出**（类似 TAL），且按「任务对齐分数」加权分类损失 |
| **Task-Aligned 预测** | 推理时把分类得分和回归质量（IoU）**相乘**作为最终得分 |

### 8.3 性能

COCO：**47.2 AP**（ResNet-101，3×），超过 VarifocalNet。

### 8.4 意义

TOOD 把 YOLOv6/v8 的 **TAL 标签分配**的理论化了 —— YOLO 系的 TAL 本质就是 TOOD 的任务对齐思想在 YOLO 架构上的实现。

## 9. RTMDet（2022）— 实时检测的极致优化

**论文**：*RTMDet: An Empirical Study of Designing Real-Time Object Detectors*, arXiv:2212.07784
**作者**：Liao, Li, Han, Ren et al. (OpenMMLab)

### 9.1 目标

**在保持精度的前提下，把单阶段检测器做到极致实时。**

RTMDet 是**纯工程优化**的典范 —— 没有新理论，全是细节打磨，但每一个都有效。

### 9.2 六个关键设计

| # | 设计 | 说明 |
|---|---|---|
| 1 | **高效骨干 (EfficientRep)** | 重参数化卷积，训练多分支推理单分支 |
| 2 | **无锚框颈部 (Anchor-free Neck)** | 用可变形卷积做特征融合 |
| 3 | **重叠感知标签分配 (Overlap-aware Assignment)** | 用 IoU 阈值筛高重叠难样本 |
| 4 | **任务对齐预测 (Task-aligned Predict)** | 分类 × 定位质量 |
| 5 | **logit 重标定 (Logit Re-scale)** | 修正训练/推理的分类得分分布差异 |
| 6 | **一致训练/推理分配** | 训练和推理用同一套分配策略 |

### 9.3 关键：标签分配的效率

RTMDet 的 assigner 是**单次前向计算的**（不像 TAL 需要额外的 IoU 计算矩阵）：

```
一次前向 → 得到每个位置的分类得分和回归预测
      ↓
计算候选位置与 GT 的 IoU（向量化）
      ↓
选出 top-k → 加权
```

**这个设计让 RTMDet 在 NMS-free 路线上也能保持速度。**

### 9.4 性能

COCO val（640）：

| 模型 | AP | 延迟 (GPU) |
|---|---|---|
| RTMDet-tiny | 41.6 | 4 ms |
| RTMDet-small | 44.4 | 5 ms |
| RTMDet-medium | 46.4 | 7 ms |
| RTMDet-large | 48.3 | 9 ms |
| YOLOv8-m (参考) | 50.2 | — |

**RTMDet 是「单阶段 + 精细工程」能达到的高度。**

## 10. 其他值得知道的单阶段模型

| 模型 | 年份 | 关键点 |
|---|---|---|
| **CornerNet** | ECCV 2018 | 角点检测（不用 anchor 也不用 center） |
| **CenterNet** | CVPR 2019 | 中心点 + 尺寸 + 偏置角（Objects as Points） |
| **CenterNet v2** | 2021 | 引入 SimOTA + 高斯分布 |
| **FCOSv2** | 2021 | FCOS + Centerness + 归一化 |
| **S2A** | 2021 | Scale-assignment |
| **FreeAnchor** | NeurIPS 2019 | 用「正样本 = 最高 IoU 的 anchor」的自洽准则 |
| **EfficientDet** | CVPR 2020 | EfficientNet + BiFPN + Compound Scaling + Focal Loss |
| **Objects as Points** | CVPR 2019 | 中心点表示（CenterNet） |
| **Swin Transformer** | ICCV 2021 | 层级 ViT 主干 |

### 10.1 CornerNet vs CenterNet

| | CornerNet | CenterNet |
|---|---|---|
| 表示 | 4 个角点 | 1 个中心点 + 2D 尺寸 + 偏置角 |
| 关键模块 | **Corner Pooling**（把特征图上的角点特征池化到 GT 角点） | **Center Heatmap**（高斯热力图） |
| 优点 | 显式建模角点 | 简单、快、旋转不变性好 |
| 缺点 | 角点对遮挡敏感 | 小目标中心定位难 |

### 10.2 EfficientDet

**论文**：*EfficientDet: Scalable and Efficient Object Detection*, CVPR 2020

三个贡献：
1. **BiFPN**：可加权双向特征融合（比 NAS-FPN 更高效）
2. **Compound Scaling**：联合缩放 backbone 深度/宽度/输入分辨率/检测器
3. **EfficientDet-D0~D7**：从 33.8 AP（参数量 3.9M）到 52.2 AP（52M）

**历史意义**：证明了「**检测器的计算效率也可以被系统性缩放**」，为后续 YOLO/FCOS 的轻量化提供了方法论。

## 11. 单阶段 vs 两阶段：怎么选

| 维度 | 两阶段 | 单阶段 |
|---|---|---|
| **COCO 最高精度** | ✅ 更强（Cascade + HTC） | 接近（GFL/VFL/TOOD 追平） |
| **推理速度** | ❌ 慢（RoI Align + N× 逐框 head） | ✅ 快 |
| **训练速度** | 慢（两阶段交替） | ✅ 快 |
| **显存** | ❌ 高（存 RoI 特征） | ✅ 低 |
| **小目标** | 中（多尺度裁剪） | ✅ 好（FPN 密集预测） |
| **密集场景** | ❌ 差（proposal 数量受限） | ✅ 好 |
| **端到端/NMS-free** | 难 | ✅ 容易 |
| **部署友好度** | ❌ RoI Align 对 NPU 不友好 | ✅ 纯卷积 |

**结论**：
- **离线精度优先** → 两阶段（Cascade R-CNN + HTC）
- **在线/边缘/视频** → 单阶段（RTMDet / GFL / YOLO 系）
- **学术追求 SOTA** → 两边都行，DETR 系也起来了

## 12. 工程结论

1. **Focal Loss 是单阶段的地基**。任何自研单阶段检测器，先确认正负样本处理方式。
2. **Anchor-free 是现代默认**。但 FCOS 的「逐像素 + centerness」和 ATSS 的「动态选点」是两套不同思路，YOLO 系的锚框自由更接近后者。
3. **分布回归（GFL/DFL）值得投入**。它是 YOLOv8+ 精度的关键来源。
4. **任务对齐（TOOD/TAL）是标签分配的现代答案**。分类和回归的监督信号应当来自同一套分配逻辑。
5. **RTMDet 证明了「工程细节的收益可能超过新模块」**。训练时的分配器和推理时的分配器保持一致，这个「一致性」原则值得记住。
6. **两阶段没死**。在 COCO 上 Cascade+HTC 的精度依然领先，且是很多蒸馏方法的 teacher。
