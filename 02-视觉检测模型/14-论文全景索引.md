```
RetinaNet → FCOS → ATSS → GFL → VarifocalNet → TOOD → RTMDet
```

```
DETR → Deformable DETR → DAB-DETR → DN-DETR → DINO → RT-DETR → DEIM
```

```
ViLD → GLIP → OWL-ViT → Grounding DINO → YOLO-World → Florence-2
```

## 7. 工程结论

1. **论文的边际收益递减很快**。读完 DETR + DINO + RT-DETR 三篇，你就掌握了 Transformer 系 80% 的思想。
2. **官方代码 > 论文**。MMDetection 的配置文件是学习现代检测器最高效的途径。
3. **复现是理解的最快方式**。跑通一个 YOLOv8 的 `loss.py` 和 `tal.py`，胜过读十篇论文。
4. **读论文要带着问题**。用 §4 的「一句话读法」作为检查清单。
5. **检测领域的核心矛盾（不平衡、召回vs定位、NMS、anchor 偏见、上下文）是不变的**。所有新论文都是在这五个矛盾上做局部改进。抓住矛盾，就抓住了脉络。
